# 吃个糖Agent v1.0.7 使用说明

## 启动

解压 Windows-x64 程序包，双击“吃个糖Agent.exe”。不要只复制 exe，程序需要同目录的 resources、DLL 等文件。

## 配音并用于视频

1. 在“模型与 API”中保存百炼账户，核对 API Key 和地域。
2. 需要创建音色时先打开独立的“复刻音色”页面，保存后再回到“生成音频”选择该音色；生成配音不会后台新建音色。
3. 打开“生成音频”，填写台词并选择内置或已复刻音色。需要“复刻音色 + 情绪指令”时选择兼容模型。
4. 支持情绪指令的模型可填写自然语言表演要求。复刻模型不支持该参数时，界面会禁用，不会悄悄忽略。
5. 点击生成，在右侧试听。生成结果自动进入资产库。
6. 点击“用于视频”，选择当前或已有视频工作区。软件自动绑定参考音频，无需下载再上传。

也可以先打开视频工作区，点击“参考音频 → 生成新配音”，完成后选择“用于当前视频”。原工作区素材与 Prompt 会保留。

## 资产和文件

- 点击左侧“资产库”展开图片、视频、音频；添加素材只保存原文件路径，不永久复制原素材。
- 新建文件夹可选上级，素材详情中可移动到文件夹；不会移动真实文件。
- 收藏素材会排到当前筛选结果顶部。
- 永久数据固定在 `D:\吃个糖Agent数据库`，程序目录与数据目录完全分离；D 盘不可用或不可写时软件会明确停止相关操作，不会静默改存到其他位置。
- 素材原文件可以位于任意文件夹。移动或改名后先在资产库刷新，再使用“重新定位文件/文件夹”恢复引用。
- WAV 可直接保存。MP3、参考人声自动转换和导入后后台视频封面使用 FFmpeg。若程序包未内置，需在设置填写可用的 FFmpeg 路径。

## 关闭

设置中选择“退出软件”或“最小化到系统托盘”。托盘右键可打开主界面或退出。有运行任务时，退出会询问；最小化到托盘不停止任务。

首次升级请先读升级说明。真实云端调用可能计费，未知费用显示“以百炼账单为准”。
