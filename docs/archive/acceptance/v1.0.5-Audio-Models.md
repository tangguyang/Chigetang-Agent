# 音频模型配置

## 首版能力矩阵

| 显示名称 | 默认 Model ID | 系统音色 | 声音复刻 | 情绪指令 | 输出 |
|---|---|---|---|---|---|
| 千问3 TTS · 情绪配音 | qwen3-tts-instruct-flash | 支持 | 不支持 | 支持 | WAV / 本地转 MP3 |
| 千问3 TTS · 复刻音色 | qwen3-tts-vc-2026-01-22 | 不支持 | 支持 | 不支持 | WAV / 本地转 MP3 |

不支持的设计音色、时间戳、Seed、语速、音调和音量参数不会作为可用功能展示。采样率显示为原生 24kHz；MP3 本地转换为 24kHz 单声道 128kbps。

矩阵定义在 `src/shared/audioCatalog.ts`，随后存入 models 表。页面不按具体模型名称编写能力分支。扩展其他协议前，必须实现对应适配与测试，不要只打开一个 capability 开关。

## 账户与地址

复用“模型与 API”现有百炼账户中的 Key、账户 ID 和 region，不额外复制明文密钥。Wan 与 TTS 采用不同接口，音频地址在“模型 → 对应音频模型 → 配置”中单独编辑。

| 地域 | 合成地址 | 复刻地址 |
|---|---|---|
| cn-beijing | https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation | https://dashscope.aliyuncs.com/api/v1/services/audio/tts/customization |
| ap-southeast-1 | https://dashscope-intl.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation | https://dashscope-intl.aliyuncs.com/api/v1/services/audio/tts/customization |

模型 ID 和地址可修改，region 使用所选账户地域。默认选择已启用且有对应连接配置的第一个音频模型/账户；这不等于服务器已确认账号权限。模型授权、余额和跨地域 Key 必须通过真实 API 验收。

复刻接口模型默认 `qwen-voice-enrollment`；返回 `output.voice` 保存为 voiceId。`target_model` 与之后合成使用的 Model ID 必须完全一致。数据库还绑定账户与地域，防止误用。

非流式 TTS 返回音频 URL。软件立即下载 WAV，按需转 MP3，保存 Artifact 并导入音频资产。失败下载可恢复，不重新调用合成 API。网络中断导致提交结果不明时暂停，避免重复扣费。
