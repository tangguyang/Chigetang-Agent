# v1.0.5 已知问题与验证边界

1. 未使用真实百炼账户执行付费生成或声音复刻。本地测试使用可检查请求体的模拟服务，不能据此证明你的账户已开通模型、套餐充足或音色质量达标。
2. Windows x64 程序采用官方 Electron 运行时交叉打包。当前环境无法执行 Windows EXE，Windows 真机启动、DPAPI、系统托盘、最小化时持续生成以及关闭确认仍需实测。Linux 原生桌面启动尝试被容器禁止 socket 的权限拦截，不能当作桌面验收通过。
3. 没有代码签名证书；系统可能显示未知发布者提示。交付的是完整解压运行包，不是安装向导。
4. 复刻模型 qwen3-tts-vc-2026-01-22 不提供此适配器支持的自然语言情绪参数。界面禁用该输入；情绪配音使用系统音色模型。没有把“复刻音色+情绪指令”伪装成已支持能力。
5. 我的设计音色、三情绪并行生成和手动搬移历史文件为本轮未启用的可选项。图片仅在 Artifact/下载基础结构支持，没有新增图片生成工作台。
6. 本地验证人声的格式、大小、采样率和时长；不自动判定录音是否为单人、是否有背景音乐等语义质量。此类问题会由百炼接口返回。
7. 视频封面在约 15% 位置抽帧并缓存，无法保证这个位置永远不是黑场。失败显示占位图；FFmpeg 不可用时回退到可见卡片串行抽帧。没有实现复杂的场景择帧算法。
8. 大规模资产库采用分页、延迟搜索、缩略图缓存和索引；还未做十万级资产的性能压测。搜索包含 LIKE 模糊匹配，超大库后续可考虑 FTS。
9. 音频页显示最近 12 条生成结果，完整历史在任务中心分页查看。
10. 修改默认视频目录会更新仍使用旧默认目录的未提交工作区，已提交任务保留自己的输出目录快照；手动选择过其他输出位置的工作区保留其选择。
11. 多个旧数据源或目标目录已存在但没有可识别数据库时停止自动迁移，需明确正确路径，不自动合并。首次大体积迁移可能增加启动等待时间。
12. FFmpeg 6.1.1 作为独立可执行组件随本次 Windows 程序包附带，来源、许可证和上游源码链接在 licenses/。后续正式分发前仍应按自己的分发方式维护第三方源码与许可证材料。

已通过的检查详见测试报告；不要将历史 v1.0.4 截图当作本版视觉验收。
