## 覆盖范围

- 清理：应用自有旧音频被移除，Wan/草稿引用的音频资产及文件被保护。
- 复刻：官方 HTTP 字段、完整 voice_id、状态查询、25 秒立即拦截、非法格式、10 MB 上限、置顶/备注/默认与重启持久化。
- 生成：空台词、instruction 加权计数、参数范围、Seed、1–10 套配置、幂等提交、顺序执行、部分失败、失败项重试、WAV 下载和真实时长。
- 指令库：20 条初始化、字符上限、应用、编辑、另存、删除、收藏、历史去重、拖拽/按钮排序及重启持久化。
- 二次复刻：成品来源带入、新 voice_id、来源关系及不覆盖原音色。
- Wan 回归：页面渲染、北京连接、素材绑定、视频任务创建、请求提交路由、队列/历史、资产/项目路径和下载相关既有测试。

## Mock 与真实环境

- 阿里云付费复刻、TTS 和 Wan 生成均使用 Mock；没有读取或使用真实 API Key，没有虚构云端生成结果。
- Mock 验证了官方请求 URL、请求体、voice_id、request_id、部分失败及下载链路。
- 音频文件解码/时长、SQLite 持久化、MediaInfo、前端交互与本地构建为真实本地测试。
