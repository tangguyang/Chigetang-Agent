## v1.1.0 定向覆盖

- Wan：视频/音频 15 秒额度分别计算；15+15+15 通过，15+15+20 拦截，10+10+20 通过；视频或音频合计超 15 秒、数量、单文件时长/大小/格式、分辨率、比例、帧率、Alpha、读取失败和非法模式组合均拦截；`duration=-1` 保留为智能时长警告。
- 素材：提交前重新读取真实签名与 MediaInfo；MP3/AAC 文件头区分和 PNG Alpha 检测；失效资产可逆隐藏，记录、ID 和原文件不删除。
- 批量视频：独立页面、默认一个 Prompt、最多三个、共享配置、复制/删除/切换、独立任务请求 ID、忙碌锁和失败项保留。
- 音频：新建工作台不自动选择默认音色；任务可靠记录后恢复单套初始配置；单条成品重命名与批次名分离并持久化；本地路径打开前检查存在性。
- 默认音色：同账户最多一个、再次点击可取消、不同账户互不影响并通过 SQLite 持久化。
- 回归：既有 Wan 提交/轮询/下载、CosyVoice 顺序生成与失败隔离、音色复刻、Prompt、资产、任务、计费和配置测试继续通过。

## Mock 与真实环境边界

- 阿里云 Wan、CosyVoice 复刻和 TTS 付费调用使用 Mock；没有读取或打包真实 API Key，也没有把 Mock 结果描述为真实云端生成。
- SQLite 迁移与持久化、文件签名、MediaInfo、前端交互、生产构建、Windows PE 和 ZIP 校验均为真实本地执行。
- 当前执行环境为 Linux，不能执行 Windows PE；未完成 Windows 真机 GUI 启动、系统托盘、资源管理器选中文件、DPAPI、音频设备和 100%/150% DPI 验收。
- 当前环境没有可用的 Chromium 可执行文件，因此未运行像素级/真实浏览器视觉回归；已运行 58 项 jsdom 结构与交互回归，并通过生产 CSS/JS 构建。
