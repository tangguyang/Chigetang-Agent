# 吃个糖 Agent v1.2.2｜Windows 验收清单

1. 在旧目录副本和数据库备份完成后解压新版，运行 `吃个糖Agent.exe`。
2. 确认界面版本为 1.2.2，历史任务、资产和账户未丢失。
3. 打开“一键生成”，确认默认空白且顶部只有“导入 ZIP”。
4. 导入单任务 V2.2 模板，核对 2 图、2 视频、2 音频、只读 Prompt 和 6 个 Wan 槽位。
5. 修改分辨率和“生成声音”，重新预检；确认不再报 `不支持修改参数：audio`。
6. 导入多任务 V2.2 模板，核对 3 个 Segment 的人物、动作视频和音频不串段。
7. 使用用户自己的默认 Wan 账户完成一次明确确认后的少量任务；核对请求参数、费用、状态与下载结果。

Windows 真机和真实 API 验收完成前，不将交叉打包结果描述为真实云端生成成功。
