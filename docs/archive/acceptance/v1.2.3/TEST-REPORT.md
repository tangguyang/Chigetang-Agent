## 结论

UI 修改已完成，95 项核心自动化测试、62 项界面测试和 5 种窗口尺寸的浏览器渲染检查通过；Windows x64 程序完成交叉构建。

## 已实现需求

| 需求 | 结果与实现 |
| --- | --- |
| 移除长视频 | 删除导航项、页面导入、路由分支和 BatchGenerate.tsx；不删除旧任务、数据或服务层 |
| 一键生成置顶 | 首项为一键生成，其后视频生成、音频生成，其余菜单相对顺序不变；内部页面键不变 |
| 一键生成任务列表调宽 | 拖动右侧边界；默认245px、下限180px、上限420px，并按工作区可用空间自动收紧上限。支持键盘方向键/Home/End，单独记忆UI宽度 |
| 实际视频时长 | 已下载本地成品通过原媒体协议读取 metadata duration，显示最多两位小数；不读取输出配置当作实际值，不重新计算片段，不写数据库 |
| 任务列表字段 | 任务名称、状态、真实时长、创建时间（createdAt，不是 submittedAt） |
| 文件夹入口 | 标题右侧文件夹按钮复用 open({kind:'output'})，由原后端读取 settings.outputDir 并打开；不硬编码、不复制、不改路径 |
| 视频工作台列表 | 固定290px宽度，去除横向缩放和横向滚动，长中英文标题自动换行 |
| 统一标题 | 一键生成、视频生成、音频生成都显示“任务列表”，保留内部变量/API/数据字段 |
| 响应布局 | 窄窗口中输出配置转到编辑区下方且可滚动访问，宽度调整预留编辑区空间；窄于等于740px时改为纵向布局 |

实际文件不存在/无法解码时显示“无法读取”；下载失败、待生成、等待下载分别标示。音频任务明确标示“非视频任务”。读取有15秒超时，成功或失败后卸载隐藏媒体元素。

## 未完成的验收与原因

- Windows本机启动与资源管理器：当前为Linux容器，不能运行Windows PE。尝试原生Linux Electron时，环境禁止其单实例本地socket，未能完成原生桌面启动；未修改安全设置或程序核心来规避。浏览器渲染检查不能替代Windows真机测试。
- 用户原有数据库：没有用户电脑的数据文件。已在临时SQLite验证历史显示并核对数据库/路径代码未变，但不能宣称用户本机数据已实测。
- 真实Wan生成与输出：无真实账户凭据，没有进行付费调用。既有任务包、绑定、导入、预检及提交测试通过，真实生成仍需本机验收。

详细步骤见 WINDOWS-ACCEPTANCE.md。包内保留旧版本报告作为历史记录，当前结果以本目录为准。

## 数据与升级

完整解压Windows程序到新的程序目录后运行；**不要覆盖或删除 D:\吃个糖Agent数据库**。本版没有数据库迁移，不改素材、音色、任务、项目和输出目录。文件夹按钮打开当前配置的视频输出目录，未强行改为数据根目录。关闭新版后可启动旧版回退。

源码/程序包均包含本报告、逐文件变更说明、更新说明与升级说明。下载文件的SHA256见交付包旁的 SHA256SUMS.txt。
