# v1.2.3 Windows 本机验收（待执行）

以下均为待本机验收项，不是已通过的实测结论。

1. 完整解压 Windows 包到新的程序目录，运行 exe，确认左下角 v1.2.3、页面正常打开。
2. 核对数据目录仍为原目录；查看历史任务、账户、音色、素材和项目。
3. 左侧顺序是一键生成、视频生成、音频生成，其余功能顺序不变；无长视频。
4. 一键生成左侧任务列表右边缘拖大、拖小；缩放窗口后编辑与输出配置仍可操作。键盘聚焦分隔线后左右方向键/Home/End 可调整。
5. 对已下载视频比对播放器真实时长；尚未生成或文件丢失时不应显示设定时长。
6. 点击“一键生成”旁文件夹图标，确认资源管理器打开设置中的生成视频目录，而非擅自重设路径。测试自定义目录同样适用。
7. 视频生成右侧任务列表固定宽度、长标题完整换行，无横向滚动。三处任务区都显示“任务列表”。
8. 用现有成功模板导入、预检、确认后，手动提交一次真实 Wan 任务（这一步会消耗用户账户额度）；确认素材绑定、输出参数、视频下载正常。
9. 音频生成与复刻音色页可打开，历史可读。重启后上述数据仍在。

可选：运行 scripts/windows-smoke.ps1 检查进程启动；该脚本不替代人工页面与生成验收。
