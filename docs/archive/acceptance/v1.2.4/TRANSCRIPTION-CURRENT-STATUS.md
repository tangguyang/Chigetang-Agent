# 吃个糖Agent v1.2.4｜转文字功能当前状态

## 当前已经完成

- 侧边栏“复刻音色”下方新增“转文字”。
- 页面标题为“音视频转文字”。
- 标题右侧已有：任务文件夹、模型目录、模型安装说明三个快捷图标。
- 已建立任务结果目录与 SenseVoice 模型目录的打开逻辑。
- 已提供小白版 SenseVoice 模型安装说明。
- 页面视觉沿用当前软件风格。
- 软件默认启动页面保持“一键生成”。

## 当前尚未完成

当前 `TranscriptionPage` 只是 UI 骨架，尚不具备真正的转文字业务链路。

尚缺：

- 音视频文件拖入/选择。
- 文件信息展示。
- 开始转文字按钮。
- SenseVoice / sherpa-onnx 实际推理。
- FFmpeg 音频标准化调用链。
- 识别进度与取消任务。
- 时间戳语义分段。
- 转写结果预览。
- 两份 TXT 文件输出。

因此本源码当前不能完成“导入文件 → 转文字 → 自动生成两份逐字稿”。

下一步开发应严格以 `v1.2.4-转文字功能开发指令.md` 为准，并保持其他现有功能不变。
