# v1.2.0 候选源码｜升级与回退

采用项目原有构建方式，不改变既有持久化数据目录。升级前自行备份用户数据根目录、账户设置与历史任务；**不得用测试数据覆盖真实用户数据**。旧版任务包 `schema_version=1.0` 继续按旧别名规则解析；新任务包使用 `schema_version=1.1`，bindings 键不含 `@`，不得混用旧 `reference_order`。

新导入草稿存放在原数据根目录的 `projects/imported-task-packs/<sessionId>`，原 ZIP 哈希与本地修订数据分别保存；已生成任务仍使用既有 TaskService 队列。旧数据尚未进行 Windows 实机升级验证。

遇到问题时先退出应用并备份当前用户数据；恢复原版本 1.1.2 的原始程序/源码和备份数据。不要直接在用户数据目录删除新任务、音色、素材或账户；v1.1.2 不保证读取 1.2.0 新任务草稿，因此回退后不要尝试用旧程序提交新版草稿。真实付费结果应以任务页及云端状态核对，状态未知禁止自动重试。
