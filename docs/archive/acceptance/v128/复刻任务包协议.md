# chigetang.replica 1.0

ZIP 根目录包含 manifest.json，素材放入 assets/ 下。顶层字段为 schema、version、name、assets、segments。参见 examples/replica/manifest.json。

assets 每项：id（唯一字符串）、path（assets/下相对路径）、type（image/video/audio）、sha256（真实文件字节的小写 SHA256）。segments 每项：id（唯一 G001 等）、model_id（wan-safe/seedance15/seedance25/kling26）、prompt、params、bindings。bindings 每项只有 asset_id 与 role。

角色：reference_image、reference_video、reference_audio、first_frame、last_frame；实际可用角色和参数必须满足所选模型能力。可灵2.6只接入文字或单首帧，5/10秒、1080P，不支持参考视频、参考音频或尾帧。

参数为空对象时应用模型默认值。导入与预检不调用付费生成。检查每个 GEN 后预检、确认，再手动提交。修改后确认失效。异常提交轮次会锁定以避免重复计费；完整任务状态仍以任务页为准。
