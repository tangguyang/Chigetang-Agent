## 开发基线与修改边界
唯一代码基线为上传的吃个糖Agent-v1.2.8-Source(1).zip，需求依据V5.0开发文档包及后续上传的新版三段置顶短视频.txt。没有回滚或重写旧音频服务；旧共享数据库schema、音色克隆、模型调用和旧视频业务文件未修改。旧brand.ts内部版本1.2.3按哈希锁定保留，包版本及新模块版本为1.2.9。

新增src/features/realSpeech/{domain.ts,Page.tsx,style.css}和src/main/realSpeech/service.ts。主进程仅增量接入realSpeech独立IPC、受控媒体读取和退出中的活动任务提示。Renderer页面lazy load和独立Error Boundary；后端首次进入才创建独立real_speech.db，初始化单例避免并发重复创建。

## 实际完成
- 独立导航：真人口播位于音频生成上方；旧音频界面保留。
- 独立SQLite、版本级备份、事务迁移与方案应用、generating→interrupted恢复，不自动补发。
- 原稿/合成稿分开，Stable Unit ID，Beat/Generation Window分开。
- ChatGPT自然语言任务包：复制全文、生成CHATGPT_TASK.md、准备当前/上一版WAV、打开目录、记录exportId/revision/contextHash。无内置LLM、无ChatGPT网页自动化。
- 唯一两套协议、严格字段/类型/范围/引用校验、变更预览与用户确认；阻止旧方案、重复planId/hash、越权凭据/路径/SQL/Shell。
- Unicode code point计数：Han≤40、weighted≤100，本地重算、超限拦截、不截断。
- 连续及手动分段、8–15秒试演Gate、手动试演Unit范围。
- CosyVoice HTTP适配器复用账户、音色、HTTP基础设施；48kHz WAV、hot_fix拼音、受控Unit尾部SSML break、合成文本数字读法。
- 持久化request.json及快照hash/clientRequestId，双击锁，未知结果不自动重试；云端成功后保存response.json，恢复下载只GET不重发TTS。
- 输出独立revision/UUID目录，临时文件验证后atomic rename；confirmed结果不可原地覆盖，历史音频可试听。
- ffprobe检查容器、编码、采样率、声道、时长；FFmpeg实际完整解码；窗口拼接与段间停顿，重拼接不调用TTS。原ffmpeg.exe不变，仅新增ffprobe.exe。
- 10题听感诊断、问题类型对应追问、位置/时间范围/自由描述、三篇专项验收、A/B上版/本版、Repair History Before/After、三轮停止、满意固定句方案复用。
- Golden由用户完整听感确认；关键项目至少基本符合、发音与拼接检查、当前完整音频哈希匹配。旧全文被标记过期，不能被误认为当前Golden。

## 首版明确范围
- 精确停顿只接受受控rhythmData→SSML break；不接收任意XML或任意SSML。发音使用hot_fix拼音，数字可用synthesisText；接口能力在导出的任务包里明确声明。
- REGENERATE_REPAIR_WINDOW首版重生成完整Generation Window；跨接缝用相邻Window联合重生成。不做采样级局部音频裁剪，以减少接缝问题。
- 没有自动真人评分，最终可发布性必须由人试听判断。
- 同类问题到三轮后阻止继续；改音色源、窗口设计或重新导演后应作为新的诊断方案，不能通过重复Seed抽卡绕过问题定位。
