# 吃个糖Agent v1.0.4

基于上传的修正版 v1.0.3 增量开发。保留 Electron 界面、账户、素材、Prompt、任务快照、数据库及现有 WAN / Seedance 调用适配器。

- 生成模型与 API 连接合并到底部固定区域；列表独立滚动、分页置底、侧栏底部置底。
- 工作区标签双击改名，回车/失焦保存，Esc 取消；移除项目分组入口及重复命名框、侧栏新建任务。
- 首尾帧、补充参考独立绑定；不支持混合输入时明确阻止提交。WAN 官方接口明确禁止该组合，不能靠界面绕过。
- 素材卡片重新布局，缩略图放大、点击预览关闭；移除眼睛和排序按钮；用途按资产 ID 记忆并可用于 @ 引用生成的提示词。
- 时长默认 0，主动选择合法值后方可提交，前端/快捷键/后端均校验；历史任务不修改。
- 本次账户 WAN 3.0 价格为参考视频与生成视频均 ¥0.60/秒，支持账户内修改，提交前显示分项。真实时长缺失则显示无法估算。
- 统计支持人工确认费用、备注、修改审计及撤销；汇总优先人工金额，再接口实际，再已提交估算，各币种分开。
- 取得云端 ID 后约每 5 秒查询；网络异常退避。重新查询与下载不创建云端任务。
- 命名任务输出“任务名.mp4”；未命名任务按落盘时本地时间命名。过滤 Windows 非法字符及保留名称，重名（含大小写差异）递增序号，禁止覆盖。
- 左上角场记板图标统一到多尺寸 ICO、EXE、窗口和桌面快捷方式。

验证范围及未验证项目以 docs/archive/acceptance/v1.0.4-Test-Report.md 为准。


# v1.0.4 升级说明

1. 完全退出旧程序，备份整个旧程序文件夹。不要在两个版本中同时打开同一数据库。
2. 将 v1.0.4 Windows ZIP 解压到新目录。不要覆盖或删除旧目录中的数据。
3. 复制旧目录中的 data、assets、projects、outputs、logs、backups 到新程序目录（保留自定义输出目录原位置）。账户密钥依赖原 Windows 用户和电脑，请在同一电脑、同一用户下升级。
4. 双击“吃个糖Agent.exe”。首次打开自动升级数据库，并保留迁移前数据库备份；旧任务快照和账目不追溯重算。检查账户、资产、Prompt、历史及自定义输出目录。
5. 桌面快捷方式可由 scripts/create-shortcut.ps1 创建，其目标和图标均指向当前 EXE。

项目分组入口已移除，但旧项目与素材、任务关联保留。账户单价只影响新任务。修改单条任务账目不会改变服务商扣费。

轮询设置：新版明确记录主动修改标记；旧版没有“是否自定义”的记录。旧值非 15 秒会保留，旧值 15 秒视为旧默认迁移为 5 秒；如果曾主动选了恰好 15 秒，升级后需重新设置一次，无法从旧版数据可靠区分。

升级后的数据库不可直接用旧版本打开；回退请使用完整备份。
