## 旧数据与计费安全

数据库新增 schema v3 人工费用与审计表，迁移前保留备份。迁移回归覆盖旧资产、Prompt、任务快照、账户密文、价格快照及项目关联。人工账目独立存储，轮询更新不会覆盖；服务商原始响应仍保留在任务 rawResult，估算不伪装成实际扣费。

生产调用链仍使用原有 WAN/Seedance 适配器及桌面网络实现。本次未提供真实账户，因此所有网络链测试使用 mock，验证任务 ID、查询、结果处理与下载分支，不产生真实扣费。已有重复 requestId 防重复建单、提交超时不自动重新提交和恢复任务 ID 的测试均通过。

## 明确限制 / 未完成实机验证

1. **未在真实 Windows 10/11 电脑启动 EXE**，未实测 DPAPI 解密、Explorer/任务栏图标缓存、桌面快捷方式、Windows 显示缩放、多显示器和真实系统通知。交付程序为实际构建的 Windows 包，但本报告不宣称 Windows 实机验收完成。
2. **未执行真实付费模型请求**，未验证该账户 WAN/Seedance 权限、服务商现场限流、真实视频画质及实际账单金额。调用、轮询、下载的自动化验证为模拟服务端响应。
3. 旧 v1.0.3 未保存“轮询间隔是否主动修改”的来源。旧值恰好 15 秒时无法区分默认与用户主动选择，迁移按旧默认处理为 5 秒；如曾主动设为 15 秒需升级后重设。其余旧自定义值保留，新版可准确保留主动设置。
4. 当前 WAN 官方接口明确规定 first_frame/last_frame 与其他 reference 素材互斥。补充素材入口不能改变服务商能力；混合输入会阻止提交。其他适配器沿用原能力限制，未启用未经验证的混合调用。
5. 未进行商业代码签名，Windows SmartScreen 是否提示依用户系统环境而定。

WAN 素材组合及持续查询依据：[阿里云 WAN 3.0 API 文档](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)。本次 0.60 元/秒来自用户指定账户规则，不是引用该文档的统一官方定价。
