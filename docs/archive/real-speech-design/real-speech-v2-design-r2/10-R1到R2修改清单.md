# R1 → R2 全量修改清单

R1保留在../real-speech-v2-design；本包是独立R2，Profile版本升为1.0.0-draft.2，仍未冻结。完整逐行文本差异见review/R1-to-R2.diff；所有内容文件新增/修改/不变状态及两版SHA256见review/file-diff.json。

## 五项评审修改

1. 增加09与spike目录：冻结前Capability Spike，38个离线case/42次候选请求，逐阶段付费批准、完整输入快照、盲听及PCM重复比较；无调度脚本、无真实调用。多个speak的轻度rate/pitch、反向与换序对照保留首版候选资格。
2. common.directorReference只要求sourceType，Plan允许null；documentId/version/hash/confirmation与Window.directorBlockIds均可选。软件导入以用户声明建立本地确认记录，文件缺失不是执行门槛。新增无附件主样例及可选附件对照，重新绑定Plan/Patch hash。
3. 03替换为32条A—G词典，新增director-dictionary.json可检索索引，含每词独立实现路径、限制及误用。B可以直接复制给ChatGPT，不等于直接送API的instruction。
4. common.intentRange与Plan.intentRanges新增展示结构；Patch.set.intentRanges支持目标范围说明更新。字段覆盖文字区间、重点词、导演意图、速度/停顿/情绪/关系感、E级、执行路径及限制。明确只展示/诊断，说明变更不建付费任务。SSML新增speakSegments与sub节点，加入两份候选样例。
5. Manifest拆分modelSupport与productPolicy.capabilityAvailability。补sub、parallelSpeak、speakRangeRate/Pitch/Volume及六元素/属性清单，保留模型官方真值；产品启用待Spike，不能用“未开启”冒充“不支持”。02重核官方依据。
