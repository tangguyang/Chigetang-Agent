# ChatGPT真人口播导演意图沟通手册｜V2设计稿

适用：听得出声音不对、但不懂声音工程的人。引用 `COSYVOICE_CAPABILITY_PROFILE.v1.json`，`capabilityProfileId=aliyun.cosyvoice-v3.5-plus.cn-beijing.http`，`capabilityVersion=1.0.0-draft.1`。必须与Manifest一起提供给ChatGPT。

1. 活人感的八个方面；2. 听感问题怎么说；3. 导演词典；4. 精确与近似；5. 导演确认方法；6. 音频诊断边界。

## 活人感指什么

活人感是“一个人理解这句话、带着目的对你说”，不是增加喘气、塞满停顿或刻意口误。讲话必须先把意思说清楚，再形成自然的力度变化。

| 维度 | 小白可直接说的话 | 执行边界 |
|---|---|---|
| 语义停顿 | “这两件事要分开说；价格出来前留一下。” | ✅指定位置break是E0；△自然思考感是E2 |
| 速度变化 | “解释部分别赶，最后一句干脆一点。” | ✅整Window rate是E1；△句内变化E2；⚠需要稳定局部变化时可建议Window |
| 重音层级 | “我想让人记住‘不用另外买’，不是每个词都重。” | △Instruction E2；❌逐字力度百分比无精确接口 |
| 情绪变化 | “先有点好奇，讲清楚以后更笃定。” | △E2；⚠差异太大可建议Window，但要用户确认 |
| 聊天/临场感 | “像手机前回答一个朋友的问题，别像录广告。” | △E2，不保证音频每次都达到 |
| 人物连续性 | “前后是同一个人同一次录制，别突然换成主持人。” | ✅锁音色保证选同voice；△状态连续仍为E2；多Window可能增加接缝风险 |
| 销售能量曲线 | “开头抓住人，中间解释清楚，报价格提一下再收住。” | △E2，曲线只作导演参考；⚠Window增强局部控制 |
| CTA自然度 | “像顺势提醒看链接，别突然喊下单。” | △E2，不能保证成交率 |

标记说明：✅只说明存在真实参数/结构控制，分E0/E1，**不代表听感绝对精准**；△通过Instruction近似；⚠经用户确认后可拆Window增强，但可能牺牲连贯性和增加试听成本；❌要求精确控制时当前没有接口。一个需求可以包含多种标记，必须分解后说明。

## 常见听感问题 → 怎么告诉ChatGPT

| 听起来不对 | 可以直接复制的反馈 | 实现判断 |
|---|---|---|
| 太像念稿 | “句句一样整齐。我希望像边想边解释，不要每句都同样收尾。” | △人物状态和句尾自然度E2；不要软件自动添口误 |
| 太平 | “开头有疑问，中间给理由，价格才是重点，现在三段没变化。” | △E2；⚠确认后分别Window |
| 太像广告 | “每句话都在用力卖，改成我自己用过、给熟人讲的感觉。” | △E2；不能擅自增加‘亲自用过’事实到台词 |
| 太激动 | “兴奋过头，像喊活动。把情绪压下来，价格重点保留。” | △E2；✅整体volume只调音量E1，不等于降低情绪 |
| 太端 | “像主持人，不像普通人在手机镜头前聊天，句尾不要端着。” | △E2 |
| 不够抓人 | “第一句要像真的在问我，后面的解释再松下来。” | △反问E2；⚠开场Window |
| 不够亲近 | “距离太远，像台上介绍，改成跟身边一个朋友说。” | △E2，不擅自改变音色 |
| 没有价格高潮 | “报价格之前留一点期待，数字说清楚、略提精神，下一句收住。” | ✅停顿E0；△数字状态E2；⚠价格Window |
| 重点没出来 | “重点是‘一套’，不是‘今天’，别把全句读成重音。” | △E2；❌逐字emphasis数值 |
| 转折不明显 | “前面是常见想法，‘但’以后是我要说的新理由，转过去要听得出来。” | ✅break E0；△转折状态E2 |
| CTA太硬 | “最后一句像推销员催单，改成说完顺手提醒，别突然升音量。” | △E2；✅整Window volume E1仅基础校准 |
| 前后不像同一个人 | “第二段突然嗓门/状态变了，延续第一段的人物关系和力度。” | ✅核对相同voice E0；△连续状态E2，先对照参数，不自动合段 |
| 数字念错 | “99读九十九，不是九九；这一处发音要清楚。” | ✅say-as/cardinal E0或确认后的合成文本；不靠提高情绪修发音 |
| 某词读错 | “这里的‘行’要读hang2，请修这个词，别改别处。” | ✅phoneme或hot_fix E0，仍需听实际结果 |

## 导演词典

| 导演词 | 具体意思与可用描述 | 能力标记 |
|---|---|---|
| 反问 | 真对对方提出疑问，不是播报问号：“你是不是也这样？” | △E2 |
| 轻微调侃 | 带一点会心笑意，不嘲讽、不大笑 | △E2；❌精确笑声时点/强度 |
| 熟人感 | 对一个熟悉的人直接解释，无舞台距离 | △E2 |
| 压低 | 可以是情绪克制，也可以是整体音高降低，先确认指哪种 | △前者E2；✅后者整Window pitch E1 |
| 提气 | 精神集中、准备抛出重点，未必更大声 | △E2，不等于volume加值 |
| 收住 | 重点说完，尾句落稳，不继续兴奋 | △E2 |
| 松弛 | 讲话不赶、不端，但信息仍清楚 | △E2；✅整Window稍慢可rate E1 |
| 戳痛 | 指出用户真实烦恼，像理解对方，不夸大焦虑 | △E2，台词事实需另外确认 |
| 专业解释 | 讲清理由、数字清晰，避免播音腔 | △E2；✅必要读法标注E0 |
| 数字爆点 | 数字是句子的重点，短暂提精神，不变喊麦 | △E2；⚠价格Window；❌逐字重音强度 |
| 降能量 | 情绪和销售压力减弱，转入轻解释 | △E2；不能用volume自动替代 |
| 克制成交 | 提醒下一步，态度确定，给人选择空间 | △E2 |
| 悬一下 | 关键答案前暂留间隔，别拖长制造假神秘 | ✅break E0；△期待感E2 |
| 干脆 | 收尾清楚利落，不拖尾 | △E2；✅整Window快一点可rate E1 |

## 怎么确认导演稿

先阅读按原稿顺序的《真人口播导演确认稿》。检查“重点有没有理解错”“情绪是不是你要的人”“有没有改台词”“哪里只是近似”。只确认导演意图，不必为所有句子填写数值。

若要求“那个字音高精确+8%”，ChatGPT应明确说：当前没有逐字声学曲线接口；可改为“这句略扬、那个词自然强调”，但这只是近似，可能强调不到或损失连贯性。用户接受后写入确认稿；不接受就标unresolved。未经确认不偷偷替换要求。

最后用户明确回复“导演稿确认”，ChatGPT才进入编译。软件不会替用户完成这一步。

## 诊断如何避免假装听过

必须有实际可访问的WAV并确认当前ChatGPT会话具备音频分析能力，才能下听感诊断。仅拿到文字/波形截图/请求参数时，只能做执行检查和假设分析，明确未听音频。不能声称“我听过很自然”。若此会话不能读取WAV，依靠用户反馈给候选Patch，标为用户反馈推断，或换能分析音频的会话。

用户反馈十维固定字段：面对镜头感、念稿感、语义停顿、快慢变化、重音层级、情绪变化、连续表达感、广告/播音腔、销售推动力、CTA自然度。每项可选“好/有问题/不确定/未评估”，加一句补充即可。诊断包不要求十题全填；Golden最终确认要明确整篇试听、发音、接缝和用户愿意采用。
