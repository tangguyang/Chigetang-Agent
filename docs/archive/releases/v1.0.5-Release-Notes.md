# v1.0.5 更新说明

本版保留 v1.0.4 账户/API、现有模型、Prompt、工作区、资产、视频调用链和历史任务。

- 用户数据独立于程序；旧数据复制迁移、升级前数据库备份、整批迁移失败回滚。
- 左侧拆分生成视频/生成音频；音频草稿保存到 SQLite。
- 百炼 HTTP 配音与声音复刻：能力矩阵控制音色、情绪和参数，音色绑定账户、地域及具体模型。
- 配音生成、试听、采用、自动保存资产、重新生成和选择工作区绑定参考音频。
- 视频参考音频选择器：最近生成、全部音频、收藏音频、试听及新配音入口。
- 同一任务表承载音频/视频，任务中心默认全部，移除未提交草稿区。
- 输出 Artifact 与下载器支持 MP4、WAV、MP3、PNG、JPG，不再固定 MP4。
- 资产逻辑文件夹支持多层级；收藏置顶兼容搜索、文件夹和类型筛选。
- 视频封面后台串行提取约 15% 位置并缓存；无 FFmpeg 时可见卡片串行解码回退。
- 保存目录可分别配置；关闭窗口/托盘偏好永久保存。
- 修复素材改名后被误判格式，及模型切换将音频模型带入视频工作台的问题。

详细验证边界和待实测事项见测试报告、已知问题及 HANDOFF.md。
