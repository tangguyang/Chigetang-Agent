# 吃个糖Agent v1.0.8｜音色复刻专项补丁

- 新增 CosyVoice 3.5 Plus / Flash，官方模型 ID 分别为 `cosyvoice-v3.5-plus` / `cosyvoice-v3.5-flash`，仅开放北京地域连接。
- 复用既有 HTTP 音色创建、上传、配音、下载及任务历史；音色严格绑定模型、API 连接与地域。旧音色不会自动重制，也不能跨 CosyVoice 型号使用。
- CosyVoice 支持 Seed，默认 12345，整数范围 0–65535；保存到任务快照，编辑/重新生成时可复用。支持语速 0.5–2、音调 0.5–2、音量 0–100。情绪指令最多 100 字符，汉字按 2 字符计。
- 复刻模型与 API 选择移入“创建新音色版本”弹窗；保留名称、参考音频、旧音色列表、试听及历史。
- 菜单使用现有 brand.svg，不改设计与布局。Vite 将图片嵌入生产资源，避免 Windows 本地路径失效。
- 现有 Qwen-Audio、Qwen3 VC、系统音色的请求逻辑保留；没有新增依赖。
- 首次升级前自动备份现有 SQLite 数据库；备份失败停止启动。数据库表结构未变，新模型以事务添加，旧 API、voice_id、任务和素材记录保留。

## V1 / V2 对比

分别在弹窗创建 V1、V2，使用同一模型和 API。生成时保持台词、指令、Seed、语速、音调、音量一致；先用自动时长及 WAV，避免本地变速影响比较。Plus / Flash 需分别创建音色。每次创建音色和生成配音可能产生费用。

Mock 只验证软件的协议、保存和参数一致性，不能证明真实声音相似度或云端重复生成效果。本版本没有执行真实付费云端测试。
