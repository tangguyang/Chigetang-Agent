# 吃个糖Agent v1.1.1 更新说明

发布日期：2026-09-21

## 主要更新

- Wan 3.0 本地参考音频超过 14 秒时，提交前自动生成前 14 秒 WAV 缓存产物。任务快照和实际上传均绑定裁剪产物，原文件不覆盖。
- 批量视频的“自由参考 / 首尾帧”改为显式状态，无素材时也可稳定切换；兼容 v1.1.0 的原存储 key 和 Prompt。
- 自动分段子任务在全部分段准备完成前不进入付费队列；视频组不再虚占 API 并发，统计不再重复计入父级聚合费用。
- 音频提交结果不明时显示“提交结果待核对”，禁止一键重试造成重复付费。复刻音色提交后保留可恢复证据和 voice_id。
- 音频结果新增 Modal 重命名、单条记录删除、完整“修改”恢复及按语速、标点和历史样本的时长预估。删除记录不删本地 WAV。
- 统一资产有效路径解析：托管副本丢失时可回退原文件；同哈希重导入可修复已失效记录；实际上传使用已验证的路径。
- 任务删除取消二次弹窗，复制任务入口替换为“打开文件位置”；运行中云任务不允许用本地删除伪装取消。
- 侧栏可拖拽并记住宽度；“统计”合并到“模型与 API”；文件导入记住上次成功目录；生成页隐藏模型/API 下拉并自动绑定符合条件的默认账户。

## 兼容与数据

- 本版没有新增数据库迁移，schema 仍为 v7。
- 不清空 API Key、音色 ID、素材、Prompt、任务、费用或输出。
- 新的裁剪缓存位于用户数据目录 cache/wan-audio-trims，不会写入原音频所在目录。

## 验证边界

自动化回归、真实 FFmpeg 裁剪、前端构建和 Windows x64 包结构验证见 docs/archive/acceptance/v1.1.1-Test-Report.md。Linux 环境未执行 Windows 真机启动、DPAPI、资源管理器、音频设备或真实付费 API 验收。
