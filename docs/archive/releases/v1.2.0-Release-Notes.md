# 吃个糖 Agent v1.2.0｜R4 最终候选版修复说明

版本号保持 `1.2.0`。本轮以 R4 Candidate 为唯一基线做最小补丁，没有重写一键生成、任务队列或 Wan 3.0 调用链。

## 修复

- 无字幕检查按动作子句判断，新增 `且`、`或` 和英文连接词边界；明确的添加/生成/显示/叠加字幕、屏幕文字、水印指令会被拒绝，合法负向约束继续通过。
- 预检在隔离副本上运行，并用逐会话原子提交门禁发布结果；编辑发生后，旧预检不能覆盖 revision、费用有效状态或确认快照。
- 提交锁继续在首次异步操作前同步建立；提交期间编辑、外部预检和重复提交均被阻止。
- 标准 ZIP 导入失败后，只回滚本次新建、路径匹配且没有任务/项目/云上传引用的资产记录；不确定归属时保留被引用文件并写入不可提交恢复标记。重启发现中断导入不会建立可提交会话。
- 修复生成工作台一个严格 TypeScript 空值检查错误，以及 UI 回归测试仍断言旧版本 `1.1.2` 的过期值。

## 验证

- Node.js 24.19.0；`npm ci` 成功。
- TypeScript 通过；Node 测试 91/91；UI 单元检查 59/59；MediaInfo bundle 冒烟通过。
- Windows x64 Electron 44.3.0 解压运行包构建成功；PE/版本/文件哈希/FFmpeg/用户数据排除检查通过。
- 三份 v1.2.0 正式规范未改写，已证明与生产导出函数逐字节一致。

## 发布状态

当前为最终 Candidate：已达到源码验证和 Windows 构建状态，但 Linux 构建环境不能替代 Windows 10/11 真机启动与完整非付费业务验收。未授权、未执行 Wan 付费生成。详情见 `docs/archive/acceptance/v1.2.0/TEST-REPORT.md` 和 `docs/archive/acceptance/v1.2.0/WINDOWS-ACCEPTANCE.md`。
