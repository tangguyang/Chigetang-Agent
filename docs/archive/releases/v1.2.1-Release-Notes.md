# 吃个糖 Agent v1.2.1 Professional｜正式交付说明

v1.2.1 Professional 以 v1.2.0 源码为唯一代码基线，保留原有 Wan 3.0、音频、素材库、任务中心和用户数据链路，重点完成今日冻结工作流的专业版收口。

## 核心升级

- 一键生成导入校验改为全量问题报告：能够同时列出字段、参数、素材 ID、bindings、Prompt 引用、素材哈希和未声明文件等多项错误，减少反复修一项、再导入的循环。
- 新增“清空任务”：只清理当前未提交任务包草稿；已提交审计记录、状态未知批次和被其他任务引用的素材受保护。
- 已提交的同一任务包再次导入时，自动生成新的内部 `task_id`，允许开启新一轮付费生成；仍必须经过预检、费用估算和用户确认，不会因导入而自动扣费。
- 保留对“提交中/状态未知”的保守阻断，防止云端已受理时自动重发。
- 内置并可直接导出今日冻结的第一阶段 V1.1、第二阶段 V1.1、黄金模板转换指令 V1.2，以及成功的单任务/多任务 ZIP 模板。
- 内置第一阶段指令已锁定年轻面部、无常见衰老皱纹、3–5 秒镜头变化及禁止生成字幕。

## 协议与兼容

- 应用版本升级为 `1.2.1`；成功模板的任务包机器协议仍为 `schema_version: 1.2.0`，避免破坏已验证的 ZIP 结构。
- 导入器仍明确识别历史 1.1/1.0 协议；新建包优先使用内置成功模板。
- 未修改用户数据根目录、账户密钥存储、素材原路径引用、历史任务或 Wan 3.0 云端请求协议。

## 验证

- TypeScript 严格类型检查通过。
- Node 自动化测试 94/94 通过。
- React/jsdom UI 单元检查 59/59 通过。
- MediaInfo 真实 MP4 bundle 冒烟测试通过。
- 单/多任务成功模板通过真实 ZIP、CRC、SHA-256、素材绑定和整数时长专项回归。

当前环境不代替 Windows 10/11 真机启动、DPAPI、托盘和真实 Wan 付费任务验收；该边界在验收报告中单独列出。
