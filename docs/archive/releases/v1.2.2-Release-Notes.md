# 吃个糖 Agent v1.2.2 发布说明

## 修复结果

- 修复修改分辨率、画幅、时长等配置后，保存阶段报“`不支持修改参数：audio`”并导致无法提交的问题。
- `audio` 现在按原有 Wan 参数语义作为布尔声音开关，可从任务包读取、在页面修改、持久化、重新预检并随任务提交。
- 一键生成默认空白，不自动恢复之前导入的任务包；Prompt 和素材只读核对，避免软件静默改变 ChatGPT 已冻结方案。

## 协议与多素材

应用版本升级到 1.2.2，任务包机器协议仍为 `schema_version: "1.2.0"`。未增加新字段或新结构。

同段多图、多视频、多音频继续使用多个唯一别名：每个 bindings 键绑定一个素材 ID，Prompt 使用同名 `@别名`。软件按真实素材类型稳定映射到 `@ImageN`、`@VideoN`、`@AudioN`。

## 配套文件

- 阶段1、阶段2、阶段3指令 V2.2。
- 单任务测试模板 V2.2：1 个 Segment，2 图＋2 视频＋2 音频。
- 多任务测试模板 V2.2：3 个 Segment，段级素材 ID 独立，不串段。

## 验证边界

已执行 TypeScript、Node 全量回归、UI 回归、真实媒体任务包解析、bundle 冒烟和生产构建。Windows 包为 Linux 环境交叉打包产物；仍需在 Windows 10/11 上使用用户自己的账户完成非付费预检和少量真实 Wan 验收。
