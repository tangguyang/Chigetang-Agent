# 吃个糖Agent v1.2.5 第一阶段执行准确性补丁

本版基于用户上传的 v1.2.4 转文字完整源码升级，保持任务包 `schema_version: 1.2.0`、既有 Windows 用户数据路径和其他工作台原有操作。

## 完成的修改

1. **参考音频按确认时长使用**：Wan 参考音频长度在接口范围内时直接使用原资产；单段超过 15 秒或合计超过 15 秒时，预检拒绝并说明要制作对应的独立参考片段。取消此前对超过 14 秒文件自动取前 14 秒的缓存裁剪。不会改变已有任务和历史裁切缓存；恢复旧裁切素材时提示它已被旧版处理。
2. **明确关闭默认 Prompt 改写**：Wan 新任务即使 ZIP 没有 `prompt_extend` 字段，也会明确传 `false`；原任务包显式设为 `true` 时予以保留，并在一键生成预检页面提示风险及提供开关。任何开关修改都使旧预检和确认失效。
3. **逐段实际提交核对**：展示参考素材的槽位、真实时长、登记的 SHA256、编译后的云端 Prompt、完整参数、账户及输出目录；展示全部片段的警告和错误，提交前重新预检并比对用户确认的快照。
4. **恢复未完成任务包**：一键生成新增“恢复未完成任务”。恢复待提交草稿将清空旧确认与预检，重新检查文件和费用；提交状态未知的批次只能查看已有记录，不能自动再次提交。新入口不自动改变首页当前导入任务。

## 使用方法

导入标准 ZIP，查看每段素材及“实际提交核对”，在右侧确认声音与 Prompt 智能改写状态，点击预检、确认、提交。若提示音频超出限制，请用已确认的时间区间制作不超过 15 秒的参考音频后重新打包；完整克隆配音仍作为后期完整声轨。

## 兼容与限制

任务包机器协议仍为 1.2.0，历史 1.0/1.1 导入能力和用户数据目录不变。此补丁不实现软件自动制作 ZIP 或最终视频组装。自动化测试只验证本地处理和模拟云端请求，不代表已运行 Windows 真机或完成真实付费 Wan 生成。
