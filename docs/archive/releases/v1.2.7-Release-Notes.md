# 吃个糖Agent v1.2.7｜第二阶段本地任务编译

一键生成新增「导出编译模板」「本地编译已确认方案」。软件读取用户已确认的 JSON 1.0 和同目录真实媒体，每段 GEN 按原片绝对毫秒区间重新编码视频，并按完整配音绝对区间生成独立 WAV。SHA-256、ZIP CRC、真实时长、素材别名及标准任务包 1.2.0 字段由生产解析器和编译器复核；完整配音原文件留供后期使用。源视频参考超过 15 秒或实际裁切输出超过 15 秒均阻止生成可提交包。

输出 ZIP 后尝试导入草稿；未配置模型、账户或输出目录时保留 ZIP 并显示导入错误，设置好后可再点「导入 ZIP」。编译与导入不调用收费模型。提交仍需逐段预检、费用核对、确认与手动操作。

SHOT 与 GEN 分离。`shot_ids` 和 `active_edit_range_ms` 记录在 ZIP 内时间表，不自动把短 SHOT 单独变成 Wan 任务，也不自动剪辑最终取用区间。KEEP、POST_FIX 不需 Wan，HYBRID 的包装贴回需要后期完成。当前仅接受已确认的结构化 JSON，不从自由格式 Markdown 猜测区间和 Prompt。未经 Windows 真机和真实付费 Wan 验收。
