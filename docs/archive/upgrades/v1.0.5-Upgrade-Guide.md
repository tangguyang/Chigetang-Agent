# v1.0.4 → v1.0.5 升级说明

## 第一次升级

1. 关闭旧版，等待任务完成；备份旧软件完整目录。
2. 将 v1.0.5 程序包完整解压到旧程序目录并覆盖程序文件。首次迁移完成前，不要删除旧版 data、assets、projects、outputs、backups 等数据目录。
3. 启动新版。默认新数据根目录为 `%APPDATA%\吃个糖Agent\UserData`。
4. 程序检测旧便携目录和旧安装目录，以 SQLite 一致性快照复制数据库，并复制标准数据目录。旧目录保留。
5. 升级数据库前自动生成 `data/pre-migration-v3-时间.sqlite`，在单个事务中执行 schema 4。
6. 确认账户、Prompt、工作区、素材和任务都在。自己的外部引用素材仍应保留在原路径。

如果多个旧目录同时有数据库，软件会停止并告知冲突，不会猜测或合并。可由交付人员设置 `AIVIDEO_LEGACY_ROOT` 明确指定旧数据根目录，再启动。

如果旧版位于其他目录，使用 `AIVIDEO_LEGACY_ROOT` 指向该旧目录；不要把一个空的新目录当作旧数据路径。

## 后续升级

关闭软件，覆盖程序包中的程序文件，再启动即可。独立 UserData 不在程序包内，不受覆盖影响。自定义输出/素材目录也保留。不要删除 `%APPDATA%\吃个糖Agent\UserData`。

## 迁移失败

程序停止启动并显示原因；数据库事务回滚，不清空任何表，旧目录保留。检查磁盘空间、目录写入权限或数据库版本后再处理。迁移快照在 data 目录，手动数据库备份使用设置中的备份目录。

## 备份与换电脑

“备份数据库”不含素材、输出视频和音频文件。完整备份需关闭软件后复制整个 UserData，以及在设置中指定的外部目录。

API Key 使用原有 Windows 系统加密。同一电脑和 Windows 用户迁移保留密文及 Chromium 配置；跨电脑或跨 Windows 用户需重新填写 Key，不要重建数据库。

## 回退

v1.0.4 不应直接打开 schema 4。需要回退时，在关闭软件后使用升级前保留的旧程序和旧数据副本，不要将旧版覆盖到正在使用的新数据数据库。
