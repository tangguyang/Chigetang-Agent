# v1.0.7 → v1.0.8 升级说明

关闭旧程序，将新版 Windows ZIP 完整解压，双击“吃个糖Agent.exe”。无需安装 Node.js 或手工修改代码。请勿在压缩包内运行，也不要只取出 EXE。

继续使用固定数据目录 D:\吃个糖Agent数据库。程序包不携带空数据库，不覆盖该目录，不删除原始素材。当前补丁不改变视频、后期或数据目录逻辑。

第一次升级在修改已有数据库之前，将一致性备份写入 D:\吃个糖Agent数据库\backups\pre-v108-时间戳.sqlite。备份失败会停止启动。新增模型以事务写入，失败回滚；重启不会重复添加。本次无数据库表结构升级。

如需回退，可关闭新版后运行保留的 v1.0.7 程序。升级前备份可用于数据恢复；恢复会回到备份时刻，请保留升级后文件和数据库副本。不要在程序运行时覆盖 SQLite 数据库或删除其 WAL 文件。

CosyVoice 需要北京 API Key 和对应 Workspace ID。原 API 连接直接复用，无需新增一套账户。账号是否开通模型，以真实接口返回为准。
