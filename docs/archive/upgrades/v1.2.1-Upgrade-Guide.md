# 吃个糖 Agent v1.2.1 Professional｜升级与回滚

1. 升级前备份完整的 `D:\吃个糖Agent数据库`（或你当前实际使用的用户数据根目录），包括数据库、设置、账户、音色、素材引用和历史任务。
2. 将 v1.2.1 Windows 包完整解压到新目录，不要只覆盖 EXE，也不要把程序解压到用户数据目录。
3. 首次启动先使用非付费流程，检查原账户、素材、音色和历史任务是否正常。
4. 在“一键生成”中分别导入内置单任务和多任务模板，确认素材卡片、Prompt、时长、预检和清空按钮正常；不需要提交 Wan 付费任务即可完成此步。
5. 已提交包再次导入时，软件会显示新的 `task_id`；这只是创建新轮次草稿，仍需你亲自预检、确认和提交。

## 回滚

关闭 v1.2.1，保留现场数据备份，恢复升级前完整用户数据副本，再启动对应的旧程序目录。不要仅回滚单个 EXE，不要让旧版直接打开经新版修改后未备份的数据库。

如遇到“提交中”或“状态未知”，先核对云端任务记录，不要通过清空、重启或重复导入尝试强制重发。
