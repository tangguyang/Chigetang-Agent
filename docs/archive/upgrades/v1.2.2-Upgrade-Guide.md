# 吃个糖 Agent v1.2.2 升级说明

1. 关闭旧版，备份完整软件目录与 `D:\吃个糖Agent数据库`。
2. 将 v1.2.2 解压到新目录，不要覆盖唯一的旧版副本。
3. 启动后确认版本为 1.2.2，账户、资产和历史任务仍存在。
4. 打开“一键生成”，页面应为空；导入 `单任务测试模板_V2.2.zip`。
5. 修改分辨率或“生成声音”，点击“保存修改并重新预检”，确认不再出现 `不支持修改参数：audio`。
6. 仅在素材、Prompt、费用和当前修订号均正确时确认并提交。

本版不迁移或升级任务包 schema；旧 `1.2.0` 协议包继续按原解析器导入。任务包中的 Prompt 和素材在一键生成页只读，修改应回到 ChatGPT 三阶段流程重新生成 ZIP。
