# v1.2.3 升级说明

1. 关闭正在运行的旧版程序。
2. 将 Windows-x64.zip 完整解压到新的程序文件夹；不要放入或覆盖 D:\吃个糖Agent数据库。
3. 双击解压目录中的“吃个糖Agent.exe”。不要单独移动 exe，须保留同目录资源。
4. 在设置页核对原数据目录和输出目录，检查历史任务、账户与音色。
5. 一键生成标题旁的文件夹按钮打开当前配置的生成视频目录。数据根目录与视频输出子目录可能不同；本版不修改既有路径。

如需回退，关闭 v1.2.3 后打开原 v1.2.2 程序。本版不执行新数据库迁移，不删除长视频历史任务，不需要复制或重建数据。

源码构建：Node >=24.19.0，运行 npm ci、npm run verify、npm run pack:win。
