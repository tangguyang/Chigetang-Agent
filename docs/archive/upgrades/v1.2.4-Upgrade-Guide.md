# 吃个糖Agent v1.2.4｜转文字补丁升级说明

1. 退出旧版程序。
2. 将 Windows x64 ZIP 完整解压到新的程序目录，双击“吃个糖Agent.exe”。不要只复制 exe，也不要覆盖用户数据库目录。
3. 软件仍默认进入“一键生成”。原有数据目录与历史数据库不迁移、不删除。
4. 点击“转文字”，再点击标题右侧 AI 图标打开实际模型目录。按文档图标中的说明安装 `model.int8.onnx` 与 `tokens.txt`；已安装指定完整版本的无需重下。
5. 选择或拖入音视频，点击“开始转文字”。模型检查自动进行，无需“重新检查”按钮或重启。
6. 完成后直接查看/复制两份 TXT，或打开本次任务文件夹。

程序已包含官方 Windows CPU 识别运行时及 FFmpeg；不需要 Python、CUDA 或开发环境。模型独立于程序。

开发者从源码构建：Node 24.19+，`npm ci`，`npm run pack:win`。运行时二进制已包含在源码 `resources/sherpa-onnx`，打包时验证必需资源存在。
首次获取 Electron/依赖需要联网；运行时识别本身不上传音视频。
