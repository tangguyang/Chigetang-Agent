# V1.2.9 修复版升级

1. 先退出旧版程序，包括托盘中的程序。
2. 解压绿色版到新的程序目录，运行“吃个糖Agent.exe”。不要把旧用户数据目录覆盖到程序目录，不要删除原数据目录。
3. 默认数据位置沿用旧版；原账号、模型、任务、素材和音色保留。
4. 左下角应显示 V1.2.9。真人口播库自动生成升级前备份，迁移版本为2。旧程序不支持该新迁移版本，不要用旧程序强行降级读写。
5. 当前任务信息可以保存修改；先试演，确认当前参数的试听后生成完整口播。
6. 删除口播工作任务不删除音频。资产库选择“音频”和“结果资产／本地素材”查看来源任务已删除的音频。
7. “一键导出给ChatGPT”仅复制文字；要分析声音，请选择诊断音频包并自己附上文件。

程序升级不会自动调用付费模型。请求未知或中断请核对原请求和账单，优先恢复下载。

绿色版无需安装。快捷方式可使用附带脚本创建。测试报告中Windows实机操作和真实模型项尚未执行，不应解读为已验证。
