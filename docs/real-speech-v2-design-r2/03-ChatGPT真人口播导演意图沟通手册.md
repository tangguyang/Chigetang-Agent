# ChatGPT真人口播导演意图沟通手册｜R2可检索词典

适用于听得出“不对”、却不知道怎么形容的人。Ctrl+F搜索词条或听感描述；将B整句复制给ChatGPT，再补具体原句、位置及真实音频。引用COSYVOICE_CAPABILITY_PROFILE.v1.json@1.0.0-draft.2；能力尚待Spike冻结。

E0=明确结构/读法控制，不等于听感保证；E1=真实参数控制，不等于精确声学结果；E2=instruction语义近似；E3=没有精确接口。一个诉求可混合多个等级。多speak局部rate/pitch是官方支持的E1候选，待Spike验证实用性，不能提前排除。不要让软件按这些描述自行导演。

查词顺序：速度与结构（语速、节奏、停顿、连说、留白、气口）；重点与语势（重音、句尾、反问、转折、数字爆点、价格高潮、CTA）；人物与状态（音高感觉、能量、松弛、提气、收住、压低、调侃、熟人感、专业解释、戳痛、笃定）；问题诊断（广告腔、播音腔、念稿感、AI平读感、前后人物状态不一致、咬字、尾字吞掉、强调对比）。
