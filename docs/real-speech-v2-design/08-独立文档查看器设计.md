## 2. 独立BrowserWindow架构

DocumentRegistry（内置documentId/标题/文件/格式/profile关联/hash）→ 主进程DocumentWindowManager → 每文档一个独立BrowserWindow → 独立DocumentRenderer＋DocumentPreload。

采用**顶层独立BrowserWindow，无parent、modal=false、alwaysOnTop=false**。不设置parent避免窗口始终压在主窗口上；辅助所属关系由Manager与退出流程管理，不靠模态父子关系。Windows原生frame保留，resizable/minimizable/maximizable/closable开启，支持拖动、最小化、最大化/还原、右上角×。不能用dialog.showMessageBox替代查看器，也不设置主窗口enabled=false。

文档入口展示名称，不再标成“①软件阶段一导演任务”。导演沟通/模板属于只读资料，可以在独立窗口阅读复制，但软件不根据台词生成导演稿。DocumentRegistry允许增加文档而无需每份写一个弹层；JSON类型Capability可高亮展示，复制原始JSON，Markdown复制原始Markdown。

主进程读取内置文档为UTF-8 rawText并形成不可变DocumentSnapshot {documentId,version,title,format,rawText,contentHash,capabilityProfileId,capabilityVersion}。正文渲染与复制都使用同一snapshot；磁盘文档更新不得使显示旧正文、复制新正文。正式升级后新开文档使用新版本；当前窗口有更新则明显提供“重新载入”，不静默切换。

## 3. 多文档实例与生命周期

Map<documentId,WindowRecord>，记录BrowserWindow、webContentsId、DocumentSnapshot、loading Promise。首次open先预留documentId，再异步读文件/创建，防双击并发开两个。若已有健康窗口：恢复最小化、show、focus，保留原滚动位置；同一份文档不会无限开窗口。不同ID能同时存在，如导演手册＋编译规范＋主工作台三窗并行。

状态链：absent→loading→ready→closed；loading失败→error/closed；render-process-gone→crashed。创建失败清Map槽位并把明确错误回主界面；ready-to-show后显示，避免空白闪烁。用户关闭只关闭对应文档，closed清本条Map和监听/计时器，保留窗口位置，不执行任务保存、删除、app.quit或其他文档close。

文档renderer崩溃：Manager记录该documentId事件，关闭坏窗口或显示可重开提示，下次open新建；不调用主程序启动失败处理，不终止主工作台。独立renderer与有限权限隔离文档故障。主进程读取/窗口管理的错误按操作捕获，不冒泡进全局启动catch。

主窗口最小化/隐藏到托盘**不等于退出**：文档窗允许继续可见，用户从托盘可恢复主工作台。真正退出遵循既有requestQuit；如果任务/草稿确认取消，不关闭文档。确认退出并完成主工作区保存、closing=true后，禁止新文档open、保存normalBounds、关闭所有文档，再继续既有任务停止和app.quit。辅助close不调用requestQuit；最后一个文档关掉而主窗口尚在时，程序继续。

主窗口正常关闭且用户选择退出时，即使文档还开着，也必须主动完成上述退出，而非等待window-all-closed。Windows会话结束/系统关机路径做尽力清理；不能把文档状态写盘失败变成退出阻塞或丢主任务。异常强制进程结束下由下次bounds校验兜底。

## 4. 永久顶部工具栏

```text
原生窗口标题栏（拖动、最小化、最大化、×）
┌──────────────────────────────────────────┐
│ 文档标题/版本          [复制全文] [关闭] │  固定工具栏
├──────────────────────────────────────────┤
│  正文专用滚动区域                        │
│  Markdown正文、列表、代码块               │
│  ……正文滚动到末尾，工具栏仍然可见        │
└──────────────────────────────────────────┘
```

推荐结构是窗口根容器100%高度，Grid两行“auto + minmax(0,1fr)”，toolbar不在正文scroll容器内，正文单独overflow:auto、min-height:0。比在同一overflow容器里随便sticky可靠；必要sticky/fixed只是辅助，不能把正文盖在工具栏下。窗口本身不产生第二个纵向滚动条。

工具栏标题min-width:0可省略显示并有完整title tooltip；操作按钮flex-shrink:0，窄窗时标题换成一行省略或标题/按钮两行，按钮始终在可见区域，不放进更多菜单。长代码块只在正文局部横向滚动，不挤出工具栏。主题由主设置快照/主题事件同步，独立窗口有浅色/深色背景、对比和focus ring；正文与工具栏配色一致。Windows缩放100%/125%/150%/200%、字体放大、窄窗时按钮可用。

## 5. 复制完整原文

点击【复制全文】→doc preload.copyAll({expectedContentHash})→主进程按sender识别绑定snapshot→await clipboard.writeText(snapshot.rawText)→返回成功。**不从document.body.innerText、当前选区、可见DOM或代码块抓取**；不包含“复制全文/关闭/版本badge”等UI文字。Markdown结构（标题、列表、段落、代码围栏）及中文从UTF-8原文件原样保留；JSON复制完整原始JSON。

成功后按钮显示“已复制 ✓”约1.5秒，再恢复“复制全文”；用清理式计时器，重复点击重置时间。请求中显示“复制中…”且仅禁用该按钮，关闭和主工作台仍可用。Promise拒绝、窗口绑定失效、文档载入失败均显示具体可理解错误，并允许重试；绝不先显示成功再等异步失败。空正文加载失败不能当作复制成功。

不暴露任意readClipboard给renderer；主进程必要时只校验本次写入，不泄漏系统原有剪贴板内容。不会为复制功能开放Node/fs/shell。复制动作也不改变Plan、版本选择或当前编辑草稿。

## 6. 窗口位置与尺寸

按documentId存储normalBounds{x,y,width,height}（DIP逻辑坐标），保存在辅助UI配置，不写task revision。debounce移动/缩放事件，关闭时最终保存；最大化/最小化用getNormalBounds，不把最大屏尺寸或最小化位置当下次默认。首版恢复正常阅读尺寸，不默认强制最大化。

首次选择主窗口所在显示器workArea，约68%宽高居中；参考最小420×300 DIP，但必须适应实际workArea，不能硬最小值大于小屏可用范围。默认留屏幕边距，允许用户最大化后并排贴靠。

每次打开校验bounds有限数值、合理尺寸、当前显示器workArea；有足够可见区域且工具栏可达则恢复，超界尺寸缩到workArea、位置clamp确保标题栏与全部按钮可访问。若原显示器已拔掉、完全无相交或存储损坏，放回主窗口显示器居中；不能只用getDisplayMatching就认为旧位置安全。支持多屏负坐标，不能把x<0一律当错。监听display-removed/metrics-changed对失去可达性的已开窗口重定位，正常可见窗口不随意挪动。

## 7. 通信合同与安全

主工作台→主进程只有documentViewer.open({documentId})，sender必须主工作台mainFrame，payload严白名单。读取文档不走RealSpeechService任务导出，不占全局生成busy，不修改任务DB，打开期间主工作台可持续编辑/试听/生成。

文档专用preload仅暴露getSnapshot、copyAll、closeSelf、openExternal、onThemeChange；主进程依据webContentsId→documentId绑定，不能信任renderer传另一个窗口ID。closeSelf定位当前sender对应窗口，不能关闭主窗或其他文档。已有aiVideo/realSpeech任务IPC保持只认主工作台，绝不为了辅助窗改成“任何BrowserWindow都可信”。

webPreferences：contextIsolation=true、sandbox=true、nodeIntegration=false、webSecurity=true；独立preload不暴露ipcRenderer和事件对象、不开放通用invoke/fs/exec。独立只读renderer只加载本地打包资源，明确CSP，Markdown禁raw HTML或做严格sanitize，不执行脚本，不远程嵌入iframe/image/active content。后续文档内容即使出现“执行命令”等字样也只是可复制文本。

文档资产用专用受控本地文档入口及路径白名单，不复用可查询全部任务音频的aivideo://asset接口。documentId映射内置路径，禁止renderer给绝对路径、../、远程URL读取；部署时无公网访问doc source。打包文件或加载失败明确错误，不能临时把软件任意文件浏览器开放出来。

全部will-navigate阻断非允许本地页面，setWindowOpenHandler deny，不让链接生成失控窗口。外链经主进程验证协议和允许host后交系统浏览器；本次审读口播/主入口只有deny，没有可直接复用的安全openExternal白名单，故需设计显式受限外链处理：内置官方来源域名（help.aliyun.com、www.alibabacloud.com、www.electronjs.org、json-schema.org、www.rfc-editor.org）只允许https；未列域名提示拒绝/提供复制链接，不允许file/javascript/data/自定义命令scheme。内部文档链接只映射DocumentRegistry并复用窗口。

非mainFrame、伪造sender、已销毁窗口、hash不符等请求拒绝。权限请求统一拒绝；renderer不访问API Key或任务写接口。构建阶段确保doc preload、renderer、registry、全部正文/profile版本打包完整，路径以app.getAppPath解析，不依赖cwd。
