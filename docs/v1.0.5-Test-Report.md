## 本轮发现并修复

- 下载器固定 `.mp4` 和 MP4 文件头，已按扩展名校验。
- 资产改名后显示名称缺扩展名，导致音频→Wan 校验失败；改用实际文件路径判断。
- 音频模型混入视频默认模型选择；现在按 type 隔离。
- 下载失败后可能重新合成；现在保留结果地址和本地下载检查点，重试不再次调用 TTS。
- 任务中心显示未提交草稿；已移除，工作区草稿仍保留。
- 多步骤 schema 迁移可能部分成功；改为统一事务和一次升级前备份。
- 目录设置变更后新工作区仍取旧 lastOutputDir；已同步默认输出路径，并保留显式自定义工作区路径。

原生 Linux GUI 尝试因为容器禁止进程单例 socket 而中止，记录在 desktop-runtime.txt。未通过修改安全检查绕过；此项不算应用逻辑通过，也不据此判断 Windows 程序有缺陷。
