# 声音复刻使用说明

1. 在“生成音频”选择“千问3 TTS · 复刻音色”，选择正确的百炼连接。
2. 点击“＋复刻新音色”，填写名称，上传参考人声。
3. 推荐 10–20 秒单人清晰朗读；软件检查 3–60 秒、≤10MB、24kHz、单声道。低采样率、多声道或不匹配格式会通过 FFmpeg 转成 16bit WAV；超过时长/大小则提示重新选择，不擅自裁剪。
4. 点击创建。服务器返回音色后保存到“我的音色”，重启后仍可选择，无需重新上传。
5. 填台词并生成，试听后点击“用于视频”。只可绑定支持参考音频且满足格式/时长/大小限制的视频模型。

“我的音色”可试听参考录音、改名、备注、收藏或移除。移除前确认，只删除本地音色记录，不删除远端音色或参考文件。试听参考录音不代表已完成合成效果验收。

当前预置复刻模型不支持自然语言情绪指令；需要情绪指令时切换到系统音色的情绪配音模型。不能将一个模型创建的音色直接交给另一个模型。

清晰人声、背景噪音、多人说话等内容质量最终由服务商评估。软件本地检查技术格式，不声称已自动判断所有人声质量条件。

创建失败时检查 API Key、余额、模型授权、地域和参考音频。提交连接中断可能已在云端创建，请先核对控制台，不要连续重复点击。
