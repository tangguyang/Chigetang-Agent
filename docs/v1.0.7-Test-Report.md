## v1.0.7 重点验收

- 使用真实 WAV 文件执行“引用入库 → 原文件夹改名 → 刷新识别 2 个失效记录 → 整文件夹批量恢复 → 历史任务按原 Asset ID 恢复读取 → 批量删除库记录”；操作前后原文件路径（恢复后的新路径）、内容和 SHA-256 一致。
- 恢复默认设置后，API 账户、素材记录和 Prompt 保留；恢复出厂后，用户原始文件及哈希不变。
- “保留成品”恢复出厂保留生成文件；“同时删除成品”只把数据库明确记录且位于固定 `outputs` 目录内的成品移入 `backups` 隔离区，未触碰原素材。
- 旧数据迁移覆盖账户密文、Prompt、工作区、素材、项目和任务；源数据库保留，目标数据库备份存在，重启迁移幂等。
- 千问 TTS 复刻请求使用 `preferred_name`；Qwen-Audio 复刻请求使用独立 `prefix`。两者均为英文数字且不超过 10 字符，不混用字段。
- 已保存 `voice_id` 重启后仍存在，配音请求直接复用；模型/音色不兼容在付费请求前被阻止。
- 真实 1.00 秒 WAV 经 FFmpeg 保音高变速校准为 0.80 秒，误差小于 0.04 秒，未裁剪结尾。
- 任务快照、上传状态、重试、防重复付费提交、失败保留输入及生成结果保存均完成回归。

## 环境边界与未验证项

- 测试环境为 Linux 容器，未提供 Windows 桌面或 Wine，因此无法在本环境实际双击 Windows EXE 并观察窗口；已完成 Windows PE、架构、资源、版本和包内运行文件校验。建议交付后在一台 Windows 10/11 机器执行一次最终启动验收。
- 未提供用户真实 API Key，未执行会计费的云端音色复刻、配音或视频生成。测试中的网络响应仅用于验证请求协议、参数、状态机和防重复提交，不宣称为真实云端成功。
- Windows 固定 `D:\吃个糖Agent数据库` 的拒绝回退逻辑已通过代码与自动化校验；本环境没有 Windows D 盘，未执行真实磁盘权限/空间不足场景。
