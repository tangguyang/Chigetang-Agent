## 本次专项验证

- Plus / Flash 分别经过 Mock：参考 WAV → 临时上传 → voice-enrollment / create_voice → 保存 V1、V2 的独立 voice_id → HTTP 配音 → 下载 WAV → 成品与历史保存 → 重启读取。
- 断言 target_model、模型 ID、API Key 对应连接、北京 Workspace URL、voice、instruction、WAV/24kHz 与所有已开启参数。既有 Qwen-Audio、Qwen3 VC 回归继续通过。
- Seed 缺省补入 12345，0 可保存，修改值可跨页面保存；两次相同输入的发出参数完全一致。拒绝负数、小数、超范围、字符串 Seed。历史快照保留 Seed，任务详情可查看。
- 拒绝跨 Plus/Flash、跨账户、跨地域音色；CosyVoice 禁止通过旧 modelMappings 绕过型号绑定。不支持 Seed 的旧模型隐藏控件且不提交 Seed。
- 弹窗实际选择 Flash 和第二个 API 连接、上传参考人声、点击创建，断言最终提交及保存绑定正确；主页已无复刻模型/API 选择框。旧音色显示与试听入口保留。
- 模拟已有数据库升级：在新增模型前生成可读且完整性正常的备份，备份内不存在新模型；原 API 密文与 voice_id 记录未改变；重启不重复备份/重复插入。
- 模拟备份目标不可用：升级停止，旧 API 和数据库保留，不插入新模型。
- WAV 原始素材字节未改变。固定 D:\吃个糖Agent数据库 与旧数据迁移沿用 v1.0.7；既有迁移、恢复测试均通过。
