# 吃个糖 Agent v1.2.1 Professional｜Windows 验收清单

## 构建环境已验证

- Windows x64 Electron 44.3.0 解压运行包。
- EXE 为 x64 PE，产品版本 1.2.1。
- 应用主进程、preload、renderer、MediaInfo WASM、FFmpeg x64、品牌图标和最终工作流资源齐全。
- 程序包不含用户数据库、API Key 或任务历史。

## Windows 10/11 真机首次验收

1. 完整解压 ZIP，双击 `吃个糖Agent.exe`。
2. 确认版本显示 1.2.1，原账户、音色、素材和历史任务仍在。
3. 从一键生成页导出三份指令和单/多任务模板，对比文件可打开。
4. 导入单任务模板，检查 3 个素材映射、Prompt、10 秒输出和预检信息；点击清空后页面回到未导入状态。
5. 导入多任务模板，检查 3 段分别为 10/10/11 秒，person/motion/voice 按段映射且不串段。
6. 制造一个同时含多个错误的副本，确认弹出内容一次列出多项错误。
7. 仅在准备真实付费验收时，提交一个小任务；完成后重新导入同包，确认显示新 `task_id` 且不自动扣费。
8. 验证关闭窗口/托盘、重启恢复、输出目录打开、视频下载和 FFmpeg 后处理。
