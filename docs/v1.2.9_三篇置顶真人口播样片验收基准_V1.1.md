# v1.2.9｜三篇置顶真人口播 Golden Acceptance 基准 V1.1

## CASE 1

目标：直接、有抓力、轻微调侃、价格清楚，但不喊卖。

必须检查：

- 开场不是广告喊话；
- 反问像真人；
- “懒宝宝/馋宝宝/又懒又馋”自然，不幼稚；
- 三拍节奏不机械；
- 99元/100杯/一杯不到一块钱清楚但不促销腔；
- CTA 不突然升能量。

## CASE 2

目标：像创始人讲自己为什么做这个产品。

必须检查：

- 开场是真问题；
- “太贵了，我喝的都心疼”像真实吐槽；
- “后来去工厂……”像讲经历，不是揭秘节目；
- “我要一杯……”坚定但不喊；
- 研发/配方仍像聊天解释；
- 重复品牌句保持同一人物习惯；
- CTA 仍是同一个人。

## CASE 3

目标：专业可信，但仍是面对镜头自然解释。

必须检查：

- 权威但不新闻播音；
- 身份介绍自然；
- 机构/成分/检测长句有自然呼吸；
- 专业名词正确；
- 连续枚举有推进和收束；
- 后段不突然变主播；
- 价格和 CTA 保持人物连续状态。

## Golden 条件

关键项至少“基本符合”：

- 真人面对镜头感；
- 不像念稿；
- 同一次录制感；
- 无明显播音/广告腔；
- 不会很快怀疑是 AI。

并且：

- 无关键发音错误；
- 无明显拼接；
- 用户愿意正式发布。

达到即可 Golden，不无限追求“全部非常符合”。
