# 吃个糖 Agent v1.2.8 源码收口验收

日期：2026-09-30。本轮沿用实际工作目录继续开发，没有重新实现或覆盖已完成的功能。仅交付源码基线，不制作 Windows 正式程序包。

## 实际完成

多引擎工作台、独立一键复刻、设置入口整合及最小 UI 调整已包含在源码中。视频转音频复用现有 FFmpeg，PDF 转图片使用本地 PDF.js。

本轮补修新复刻服务预检/确认/修改/提交的并发状态风险，立即持久化确认失效，拒绝锁定或提交完成任务的重新预检；补充严格嵌套字段校验。缺少可用密钥时在锁定前报错，保持任务可编辑。不存在的草稿模型提供显式修复入口并保留提示词和素材。无法确认的可灵提交响应归类 SubmissionUnknown，避免普通失败重提导致重复计费。

旧一键生成相关原码哈希校验继续通过；保护清单见 legacy-v124-sha256.json。完整源码差异清单见 修改清单.txt。新增唯一直接运行依赖为 pdfjs-dist 5.6.205，未重复引入 FFmpeg。

## 未验证与限制

- 未执行真实付费 WAN/可灵/Seedance 云端生成，没有使用真实账户额度。模拟接口不能证明用户账户权限、余额或实际网络条件。
- 未执行 Windows 实机启动、DPAPI、原生文件选择/拖放和资源管理器实际打开。目录接口使用替代打开函数验证，不能称作 Windows 实机通过。
- SenseVoice 真实模型集成测试因环境未配置对应模型/原生运行条件而跳过；未修改转文字业务。
- Chromium 截图环境缺少系统中文字体，UI中文字形的视觉验收未完成。中文PDF样本嵌入字体，转换后文字已另行查看确认。浏览器验证使用HTTP测试桥，未覆盖Electron file协议及原生IPC实机环境。
- 数据兼容验证使用合成已有数据库，未使用用户真实数据库。保留自动备份机制及原数据目录约定。
- 任务提交中断后使用锁定状态防止自动重复计费，需要检查已创建的任务记录；不自动重试不明提交。
