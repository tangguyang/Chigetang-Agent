- P1：落实附件的统一资产库、任务分组、文件打开图标、一键复刻目录和手册。
- P2：完善导演信息的执行能力说明、恢复流程与费用提示。不得用虚假的支持说明代替实际能力。

上述均为本版交付范围；优先级仅表示实现顺序。采用最小完整 Patch，必要时修改 UI、IPC、Service、数据库、文件与恢复链路，不做无关重构，不增加非必要依赖。

## 3. 真人口播任务详情：可编辑且可保存

### 3.1 页面与字段

创建成功进入该任务的详情工作台；顶部显示任务名称和当前步骤。新增“任务信息”区，包含名称、目标、原稿、复刻音色、已有补充描述。支持修改、保存和取消；未保存时显示“有未保存修改”。所有生成、导出和应用操作读取已保存数据。

音色显示名称及可用状态，不能仅显示内部 ID。尚未选定音色可保存草稿、导出导演请求，但禁止生成并明确提示。音色不可用时保留旧选择及原因，不能自动换成另一音色。

保存原稿前显示影响说明：将重新划分 Unit，原方案、窗口安排及试演确认失效；历史音频保留。此确认属于应用内数据影响预览，不得自动调用模型。取消不修改任何数据。

### 3.2 更新规则

| 修改 | 必须发生的状态变化 |
|---|---|
| 名称 | 更新显示和来源信息；不作废音频 |
| 目标／用于导演的补充描述 | 旧导出方案不可继续应用；提示重新导出；已生成音频不因文字目标变化而消失 |
| 原稿 | 重新切 Unit、重建有效窗口；清除当前导演关联、待执行修复和旧范围；保存历史快照；当前成品标记过期 |
| 音色 | 生成窗口待重新生成、试演失效、当前成品过期；不得沿用旧音色的通过标记 |
| 合成指令、文本、发音、节奏、rate/pitch/volume/seed | 受影响窗口待重新生成，相关试演失效，当前成品过期 |
| 仅拼接停顿 | 当前成品待重新拼接；不强制重新调用 TTS |

修改任务的原稿是用户直接编辑功能，不改变 ChatGPT 协议禁止修改 originalText/voiceId 的规则。所有实际变更递增 revision；无变化保存可直接提示无需保存，不制造假变更。原稿保持原始换行、标点，不擅自润色。

保存失败保留编辑草稿、显示原因；成功才刷新当前任务。异步操作期间不得切换任务造成数据写错；旧 revision 写入被拒绝后刷新并保留用户草稿供比较，不静默覆盖。

## 4. 新建任务表单重置

成功创建并取得持久化任务后：名称恢复“新真人口播”；原稿和补充描述清空；目标恢复软件默认；音色恢复未选择。不得把上个任务的私有台词或音色带入下一条任务。

创建失败保留全部输入；双击只能创建一条。打开既有任务不覆盖新建草稿，关闭详情返回列表不隐式新建任务。详情使用已创建任务自己的数据，不能因清空新建 draft 把刚创建的任务也清空。

## 5. 试演与全文生成的状态一致性

### 5.1 时长不再阻断有效试听

8～15 秒是建议取样长度，不是有效 WAV 的硬门槛。真实文件验证成功、时长为有限正数、当前参数匹配、用户已试听确认，允许 7.8 秒等范围外试演通过。

范围外显示：“本次试演 X 秒，建议 8～15 秒；若已足够判断，可确认通过。”不用自动补静音、调慢语速、扩大范围或再次付费。缺失文件、损坏文件、非有限或非正时长、未完成生成，不能确认。

### 5.2 确认绑定实际请求

试演确认必须绑定当前实际输入，至少包含：任务原稿／相关 Unit 文本、选定音色、试演 Unit 顺序、实际窗口参数、执行指令、合成文本策略、发音、节奏、rate/pitch/volume/seed。可复用 canonical/hash，不需为每个字段增加独立数据库表。

生成成功写入请求快照与匹配依据；反馈确认时后端重新计算并核对，不能只依赖 status 或前端传来的 hash。名称等无关改动不应使试演无端失效。

旧试演保留可试听，但标注“旧参数试演，不能确认当前方案通过”。开始新试演即撤销通过状态；失败、中断、未知结果均不恢复旧通过标记。恢复下载成功也必须重新核对并由用户试听确认。

旧版本试演缺少可靠绑定数据时：能从已有完整快照重建并验证则复用；不能证明一致时保留试听、提示需重新试演，不直接推定已通过。

### 5.3 未保存参数与试演范围

任务信息、窗口参数、试演范围有未保存修改时，阻止试演、全文生成、导出和应用方案，显示“请先保存修改”。提供就近保存操作，不能自动忽略草稿，不能为方便而静默发起计费。

试演完全位于某个窗口时，继承该窗口参数，并筛选属于所选 Unit 的节奏数据。自定义 synthesisText 无可靠 Unit 映射时，试演不得静默换成原稿且声称验证了全文设置，应说明限制并引导选定可验证的范围。

本版最简单可靠策略：试演只能选择单一 Generation Window 内的连续 Unit。跨窗口范围明确阻止并说明原因，不悄悄使用第一个窗口。导演方案指定跨窗口试演时，在预览中标明不兼容并要求调整；保留任务和旧结果，不隐式重写方案。

### 5.4 按钮与错误提示

每个禁用动作旁显示最直接的原因和下一步，不只使用灰色或悬停提示。使用“生成完整口播”或“生成本段口播”等新手可理解名称；内部 GW ID 可保留为辅助信息。

确认试演后就近显示“试演已通过，可以生成全文”；全文失败、中断、下载失败分别显示真实状态和恢复动作。错误出现在发生操作的区域，并可保留页面级摘要，不能要求用户回到顶部找错误。

纯拼接说明“不调用模型，不新增生成费用”；重生成说明会调用模型，保持原有费用确认。恢复下载不得自动变成重新生成。

## 6. 导演方案与模型执行边界

Runtime Schema 仍是执行真值，继续严格校验唯一 JSON、ID/revision/exportId/contextHash、动作、字段类型、Unit、范围及 instruction 限额；禁止截断、猜测拼音、擅自改原稿或音色。

speakerProfile/performanceArc/performanceBeats 是导演说明；当前模型直接接收的是每个窗口 instruction 及实际支持的参数。不得简单把所有说明拼进 instruction，造成超限或指令冲突，也不得未经官方能力核实新增不受支持 API 字段。

本版必须：

1. 预览清楚区分“实际发送给模型的指令／参数”和“导演参考说明”。
2. 复制给 ChatGPT 的请求明确：关键表达必须压缩到各窗口 instruction 内；遵守汉字≤40、加权≤100；其余描述不会直接执行。
3. 每次生成展示可查看的实际请求参数摘要，与持久化快照一致；不会暴露密钥、私有路径或凭证。
4. 句内快慢通过模型支持的自然语言指令尝试；rate 是整体速度，Unit 后停顿不等于五个字内部放慢。不能宣称稳定精确控制或靠切碎窗口强行实现。
5. 首版保留 seed=0，不自动抽卡；涉及新 seed 必须明确设置和确认。Director 的 seedPolicy 不得界面声称已随机执行而实际没有；本版固定初始 seed 的限制应写清。

试听效果属于真实模型和人工验收，自动化只能验证指令传递与状态，不能证明“声音像真人”或“爆款效果”。

## 7. 删除口播任务，保留音频资产

### 7.1 明确含义

“我的口播任务”每条提供删除选项；统一资产库内任务详情也提供同一动作。新手文案：“删除任务记录，保留已生成音频”。二次确认列出保留的音频数量；不提供默认勾选的实体文件删除。

删除后，该工作任务不再出现在任务列表，也不能再执行或接受旧方案；其有效试演、窗口结果、完整成品和历史版本仍在资产库的音频分类。保留独立的来源快照和必要费用／请求审计，不依赖已删除的工作记录才能播放或下载。

允许内部以删除标记和必要审计快照实现可靠删除，但对用户必须是删除工作记录，不等同附件中可随时恢复的“隐藏”。实体音频永久删除、自动清理和回收站系统不在本版范围。

### 7.2 音频入库与资产展示

- 成功生成并验证本地音频后即幂等入库，不等到任务删除才第一次处理。覆盖试演、完整窗口、最终拼接及下载恢复。
- 分类：音频；来源模块：真人口播；结果角色：试演／口播片段／完整口播；保留任务名、来源任务 ID、窗口 ID、版本、创建时间、文件引用和实际参数快照。
- 资产可独立预览、打开原文件、打开所在目录、检索。已删除来源显示“来源任务已删除”，不显示无效的继续编辑按钮。
- 旧版结果批量补齐关联，失败可重试；已有实体文件不搬动、不覆盖。旧任务被删除后，不靠任务查找 API 才能解析资产文件。
- 默认任务视图一条任务一张组卡；详情展开版本。已删除任务的音频仍可从音频／全部来源筛选找到；不得被默认“仅生成任务”筛选永久隐藏，明确提供结果资产筛选。
- 同一文件被多个任务或版本引用，保留来源关系；不能因为内容 hash 相同就抹掉不同请求、费用或版本。

### 7.3 删除安全与恢复

删除前检查后台任务是否运行；生成、下载恢复或拼接进行中禁止删除，显示原因。未知结果／中断记录需保留请求审计及恢复入口，不能因删除丢失核对费用的依据。

检查已有成功结果全部可独立访问；资产入库或快照保存失败则中止删除，原任务仍可见，允许重试。缺失文件明确展示缺失／可恢复状态，不伪装为已保留的可用音频；缺失记录同样保留来源信息。

涉及独立数据库时不能假设跨库事务自动成立。采用现有最简单幂等步骤：先持久化资产及来源快照，核对完成，再提交任务删除标记；中断后可重试补齐。删除不得直接递归移除任务输出目录，不做级联物理文件删除。

## 8. 一键导出给 ChatGPT：复制与两秒提醒

点击默认按钮后：生成当前协议文本、保存新的 exportId/contextHash、写入系统剪贴板；成功后就近弹出“已复制”两秒提醒，自动消失，不跳转、不打开文件夹，不丢滚动位置。连续点击重置提醒计时，离开页面清理计时器。

剪贴板写入失败不能显示成功，保留文本并提供手动复制。导出失败不覆盖有效上下文。新导出会使旧 exportId 方案失效，必须保持原防旧方案逻辑。

默认复制仅准备文字，不必每次复制全部 WAV；原“导出音频附件包”可作为独立次要按钮保留，由用户主动选择准备附件和打开位置。不得删除已有导出或原始音频。

复制文本准确说明是否存在音频、是否已实际附给 ChatGPT。剪贴板文字无法自动附加 WAV，不得写成“已上传音频”；有音频时提示可单独附上，不能在未打开的目录中准备文件后误导模型以为看到了附件。

## 9. 统一资产库与一键复刻 UI 范围

附件全部界面要求纳入本修复版，完整内容见附录 A。版本号不升级到 1.3.0。统一入口以资产库为主，真人口播页面保留工作任务选择和删除操作；这不另建一个独立资产存储体系。

冲突处理以本文为准：附件的“隐藏、不删除任务”只用于通用列表整理；真人口播新增明确删除工作任务的能力，以第 7 节为准。音频实体均保留。附件中原“任务结果仅在详情访问”的安排不妨碍删除来源后独立音频资产可达。

### 9.1 版本号显示一致

软件窗口左下角固定显示“V1.2.9”。关于页面、软件内版本说明、导出任务上下文、package 元数据、绿色版与安装包产品版本统一为 1.2.9，不得残留 1.2.8 或显示 1.3.0。协议版本 1.2、能力版本 1、数据库迁移版本不属于产品版本，不得误改。

优先复用已有应用版本来源，必要时补充共享版本常量，避免各页面重复硬编码。构建日期或修复标识可放关于页面和升级说明，左下角仍按用户要求显示 V1.2.9。真实 production build 后检查界面与安装包信息，不能只修改源码字符串就宣称已验证。

### 9.2 一键复刻／一键复制标题左侧手册入口

用户称“一键复制”，当前源码功能为一键复刻；以现有实际工作台为修改对象，不新增重复模块。本版标题行顺序调整为：文档手册图标、文件夹图标、工作台标题。两个快捷入口均位于标题左侧；替代附录原“文件夹、标题、手册”的安排。

文档图标 tooltip 与无障碍名称为“一键复刻使用手册”。点击在软件内打开离线阅读弹窗／抽屉，包含操作步骤、与一键生成的区别、输出位置、失败恢复和费用说明；复用附录第 7 节完整手册要求。不打开源码或外部文件夹，不要求联网；关闭后保留草稿、任务选择与滚动位置。图标点击区域至少 36×36 px，支持键盘，窄窗口不遮挡标题。

新增验收 R20：运行修复版，左下角显示 V1.2.9，关于信息和包版本一致；协议与数据库版本保持各自正确值。

新增验收 R21：打开实际一键复制／复刻工作台，标题左侧文档和目录入口顺序正确；手册可离线阅读，目录打开正确，关闭手册不丢工作状态。

## 10. 数据兼容、恢复与安全

保留原用户数据目录、主库及真人口播库、账号、音色、素材、项目、费用和旧输出。版本保持 1.2.9，可在升级说明中标注修复版和构建日期；内部数据迁移版本独立递增，不用产品版本代替 schema 版本。

必要迁移先备份，可重复执行；新关联唯一约束与幂等处理避免重复。不得为了表结构整洁重写整库或批量挪动文件。任务删除、历史资产补齐、应用方案、生成状态写入和恢复均检查 revision 与后台互斥。

任何修改不得引入自动付费重试。恢复实际下载失败时保留可再尝试的信息和文件，已有有效文件不能被临时文件覆盖。修改原稿或重分组后不得残留指向旧窗口的 pendingAction。

# 资产库与一键复刻 UI 要求

适用版本：v1.2.9 修复版｜基线：当前 v1.2.9 源码｜重点：UI 与资产查找体验

## 1. 本轮目标与范围

让用户在一个资产库入口找到全部生成任务及结果，快速预览、打开文件、恢复任务；让一键复刻工作台的输出位置和使用方法随手可达。

本轮以界面和交互优化为主。仅完成支持界面所必需的 IPC、数据关联、文件操作和状态同步；不重写模型调用、计费或正常工作的生成流程，不新增非必要依赖。本文是开发要求，不代表功能已实现或测试通过。

必须交付：统一资产库、一键复刻标题工具、内置手册、原文件快捷打开、分段分组、旧数据兼容、测试及 production build。GitHub 上传不属于本轮功能开发。

## 2. 已核实的源码基础

- Assets.tsx 已有媒体类型、名称／标签搜索、文件夹、收藏、预览与导入。
- Asset 已有 hash、folder、tags、favorite、路径、媒体信息；导入服务已有哈希去重。
- Tasks.tsx 与 Task 类型保留任务状态、输出、版本、参数快照及费用。
- 数据库已存在任务与素材关联，不能直接把任务记录改成素材记录。
- 真人口播有独立任务及结果版本，需要单独接入统一展示。

- 当前一键复刻使用复刻会话、GEN 分段与可编辑草稿；一键生成使用任务包导入、逐段检查、预检估价、确认和提交。手册必须按真实支持行为编写，不宣传自动分析任意视频或自动剪辑成片。

开发前仍须核实各服务、工作台历史栏和输出保存链路，不以以上摘要替代代码理解。

## 3. 信息架构

### 3.1 统一入口

侧栏保留“资产库”，移除单独的“任务”导航入口。全部既有任务入口和工作台跳转改为资产库内定位对应任务。旧任务详情可复用，在资产库内以抽屉或详情页打开。

项目是可选关联／筛选，不在本轮重建项目系统。旧项目和关联数据保留；原入口与路由变更不得导致记录不可达。

“统一到资产库”是统一用户入口和检索，不是强制统一数据库表、复制文件或删除历史。

### 3.2 默认页面

从上到下排列：

1. 标题“资产库”；右侧“导入素材”。
2. 类型标签：全部、视频、图片、音频、脚本／Prompt。首次进入默认“视频”；后续记住用户选择。不得增加重复的侧栏类型入口。
3. 来源切换：全部、生成任务、本地素材。首次默认“生成任务”，明确显示当前筛选。查看脚本／Prompt 时隐藏不适用的任务状态筛选，提示搜索仅作用于该类型。
4. 搜索框；状态筛选：全部、进行中、已完成、失败／待处理；排序：最新、最早。默认最新。
5. 可折叠的辅助筛选：收藏、文件夹、所属项目、生成模块。不要首屏堆满下拉框。
6. 结果区与分页；显示符合条件的数量，分页按顶层卡片计算。

进行中的匹配任务排在顶部；其余按创建时间倒序，更新时间用于状态显示，不因后台轮询反复改变卡片顺序。待处理包括需人工确认、下载失败、未知结果／中断等情况，保留真实细分状态。

生成模块筛选涵盖现有普通生成、专业音频、一键生成、一键复刻、真人口播等实际模块；无历史来源信息时显示“历史任务”，不可猜测来源。

### 3.3 搜索约定

生成任务：名称、任务 ID、已保存的 Prompt／口播文本、已关联标签。素材：名称及标签。采用明确的包含匹配，不引入语义搜索。查询范围在界面说明；大文本查询应有分页与输入防抖。

单个筛选改变回到第一页。保留筛选、滚动位置及详情关闭前的位置；提供“一键清除筛选”。无结果与没有任何资产必须区分。

## 4. 卡片设计

### 4.1 生成任务卡

缩略图／音频图标与试听、状态徽标、名称、名称右侧打开文件图标、时长、创建时间、模块来源。失败卡显示简短原因；费用、模型参数和原始错误放详情。

等待与生成中也必须有卡片。没有输出时展示状态占位，不显示破损图片。图片保持原比例，视频不自动播放，音频仅用户点击后播放。

点击卡片主体打开任务详情；点击打开文件、试听、重试等操作不得触发卡片跳转。标题最多两行，悬停可看完整标题。

### 4.2 素材卡

显示预览、名称、名称右侧打开文件图标、媒体规格、来源及收藏操作。媒体规格仅显示可靠信息，不将未知值显示成 0 秒。

生成任务和其结果资产在“全部”中按来源关联合并显示，不能展示两张实质相同的卡片。没有可靠关联的旧记录不凭名称合并。文件相同而生成任务不同，保留各任务参数和费用历史。

### 4.3 快捷操作

名称右侧固定显示“打开原文件”图标，不依赖悬停才能发现。点击区域至少 36×36 px，有 tooltip、aria-label、键盘焦点。

| 情况 | 行为 |
|---|---|
| 本地文件存在 | 用系统默认程序打开卡片对应的本地结果／素材 |
| 文件不存在 | 显示不可用原因；素材提供重新定位，生成结果有可恢复链接时提供恢复下载 |
| 正在生成或未下载 | 禁用按钮并显示明确原因，另提供可用的下载／恢复操作 |
| 有多个输出 | 先选具体结果，不能任意打开第一份 |

更多菜单可提供打开所在文件夹、下载／恢复、再次生成、收藏、从列表隐藏。再次生成打开原参数草稿，不自动提交或付费。路径操作复用受信任 ID 查找与既有安全校验，不接受任意前端路径。

## 5. 分段与真人口播

一键生成和一键复刻按真实会话／父任务归组，默认一张组卡，显示名称、“已完成 X／Y 段”、失败／进行中数量。展开按原片段顺序显示子卡；可分别预览、打开结果和查看详情。

没有最终合成文件时明确显示“分段结果”，不可称为成片。重试单段只影响该段，已完成结果保留。旧任务缺少分组信息时显示独立卡，不凭时间接近猜测分组。

真人口播在音频分类展示全部任务，含未完成和失败任务。默认结果是当前可用的完整口播；没有完整口播时展示任务占位，详情中访问试音、窗口和历史版本。旧完整口播若因修改已过期，应标记“旧版本／待重新合成”，不能标记为当前已完成结果。中断与未知结果仍须原有确认和恢复流程；不得自动重新调用付费生成。

## 6. 一键复刻标题与目录

标题行左到右：使用手册文档图标、文件夹图标、标题“一键复刻”（以实际界面命名为准）。图标与标题垂直居中，与既有 UI 风格一致。

文件夹按钮 tooltip：“打开生成视频文件夹”。打开当前配置的生成视频输出根目录；不强行猜测整个复刻会话具有唯一独立目录。任务／片段详情另提供“打开该结果所在文件夹”。

未生成视频但配置目录有效时可打开／按既有目录策略创建；无法访问时提示实际原因，不静默失败，不改成其他目录。不得启动生成请求。

使用手册按钮 tooltip：“一键复刻使用手册”。点击软件内打开大尺寸阅读弹窗／抽屉，不打开代码文件，不要求联网。支持目录导航、清晰标题、正文滚动和关闭；关闭后工作台草稿、选择、滚动和任务状态保留。

## 7. 内置手册要求

面向新手，先回答选哪个功能，再解释怎样操作。短段落、步骤清晰，中文，不堆协议字段和开发术语。

必须包含：

1. 一句话说明一键复刻的实际用途和能力边界。
2. 一键复刻与一键生成的真实差异表：所需输入、编辑方式、检查／提交步骤、结果和适用场景。两者均需合法任务包和正确素材，不承诺点击一次就完成所有工作。

4. 根据真实按钮讲解导入、选择片段、检查素材／Prompt／参数、保存、预检、确认、提交、查看结果。

## 8. UI 通用标准

- 沿用现有颜色、字体、按钮和间距体系；禁止全站换肤和无关重排。
- 1280×720 可完整操作，无页面级横向滚动；高 DPI 与窗口缩放下按钮不遮挡。窄窗口筛选换行，详情可独立滚动。
- 进行中状态使用文字配图标，不只靠颜色；异步操作防重复点击。
- 加载用稳定占位；错误有原因和可执行操作，不显示永远转圈。
- 筛选无结果提示“清除筛选”；首次空库显示“去生成／导入素材”。
- 返回详情前列表位置保留；导航切换不会停止后台任务。
- 状态变化及时刷新，列表更新不抢焦点、不打断搜索与播放。跨页返回和应用重启后重新读取真实状态。
- 不自动播放所有媒体，不一次加载整个历史库。

## 9. 数据与兼容性

保留旧用户数据目录、账号、任务、费用、结果、素材、项目、收藏、标签、文件夹以及真人口播版本。不得重置数据库或移动旧媒体文件以适配 UI。

优先采用统一查询／视图层，复用任务详情；必要时新增来源关联和索引，迁移必须可重复执行、事务化，并有备份。内容去重不等于任务去重；已有素材元数据不能被自动入库覆盖。

生成结果在下载成功后可关联到资产管理；新增关联须幂等。存在多个输出时逐项建立关联；入库失败不得把原来成功的生成任务改成失败，也不能丢失其输出。

通用列表整理默认“隐藏”，不删除文件或任务历史；真人口播的明确删除任务动作按正文第 7 节执行。隐藏范围清楚说明、提供恢复入口，并与已有隐藏素材机制兼容。永久删除及自动清理不在本轮范围。

## 11. 开发及交付顺序

理解 v1.2.9 真实调用链 → 确认最小完整数据关联 → 完成统一资产库与卡片 → 复刻标题和手册 → 状态与旧数据兼容 → 定向测试 → 必要回归 → production build → Windows 实机验收。

定向测试应覆盖来源合并、多输出、分组、旧记录、文件缺失、隐藏恢复、口播过期结果和状态更新；UI 测试覆盖按钮冒泡、筛选、详情返回、手册与目录动作。真实文件打开和 Windows 缩放须在 Windows 环境验证。

交付完整源码、绿色版、安装包、SHA256、升级说明及测试报告。测试报告分别标记自动化、模拟、真实文件／媒体、Windows 实机和外部模型验证；未执行或无外部条件时明确标记，不得写成通过。本轮 UI 验证不要求无必要的付费生成。

## 12. 不纳入本轮

不重建项目系统，不新增复杂用途分类强制填写，不做智能标签或语义搜索，不增加模型，不做自动剪辑／发布，不自动删除中间文件。已有项目关联、文件夹、标签与收藏继续使用。

最终标准：用户能从资产库快速找到刚生成的任务和结果，打开正确文件，理解一键复刻操作，同时旧数据和生成流程可靠保留。
