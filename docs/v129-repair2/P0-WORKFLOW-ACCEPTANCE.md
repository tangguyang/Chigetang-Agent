# v1.2.9 修复版2｜P0 流程验收清单

> 任何 P0 未通过，不允许称“修复完成”。

## A. 不可卡死原则

- [ ] 任意 dirty 状态都有【保存】和【取消】
- [ ] 任意 disabled 按钮旁能看到原因
- [ ] 任意保存成功都有反馈
- [ ] 任意生成失败都有恢复路径
- [ ] 局部编辑不会无理由清空全局资格
- [ ] 不存在“为了保存必须先生成、为了生成又必须先保存”的循环依赖
- [ ] 不存在“修改本段后必须重新跑无关试演”的循环依赖

- [ ] 不发送模型不支持字段

- [ ] pronunciation 走真实支持链路
