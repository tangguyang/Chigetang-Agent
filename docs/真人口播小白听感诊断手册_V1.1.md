# 真人口播小白听感诊断手册 V1.1

## 一级 10 题

每题选择：

- 非常符合
- 基本符合
- 不太符合
- 完全不符合
- 听不出来 / 不确定

1. 像真实的人面对镜头讲话。
2. 不会明显感觉在念稿。
3. 像同一个人在同一次录制里说完。
4. 轻重、快慢和停顿符合内容意思。
5. 重点会自然突出。
6. 停顿像真人思考/换气，不像按标点停。
7. 有说服力，但不像播音员/主持人/企业宣传片/带货主播。
8. 人物状态从头到尾变化自然。
9. 产品名、数字、专业词、长句自然清楚。
10. 不会很快因为声音表现怀疑是 AI。

## 位置

第一次觉得不自然：

- 开头
- 前半
- 中间
- 后半
- 价格/卖点
- CTA
- 整段
- 说不清

## 最明显问题

- 像念稿
- 新闻播音
- 企业宣传片
- 直播卖货
- 太机械
- 太平
- 太用力
- 太快
- 太慢
- 停顿怪
- 重音怪
- 某句话语气不对
- 前后不像一次录制
- 音色不像本人
- 发音/数字/专业词奇怪
- 明显拼接
- 说不清，就是觉得假

## 软件行为

用户提交后，软件自动把：

- 问卷
- 问题位置
- 自由描述
- 当前参数
- 前后 Window
- Instruction 及本地计数
- Request Snapshot
- Repair History

一起放入 Diagnosis Task。

用户不负责解释专业原因。
