# 一键复刻使用手册

## 先选对工作台
一键复刻：导入复刻任务 ZIP，按 GEN 选择片段，修改素材、Prompt、模型参数，保存后预检、确认并提交。
一键生成：导入既有任务包，逐段核对内容、素材、参数，按该工作台的预检与确认流程提交。
两者都需要符合软件协议的任务包。软件不会仅凭任意视频自动完成分析、复刻和剪辑成片。参考视频拆解和导演方案由前置工作完成，生成后的分段可在剪映拼接。

## 开始前准备
准备任务 ZIP、人物及产品素材；配置可用账号、对应模型与输出目录。缺失素材先重新定位，不要直接付费提交。

## 操作步骤
1. 点击“导入复刻任务 ZIP”，选择已准备好的任务包。
2. 选择一个 GEN，检查素材、用途、Prompt、输出时长、画面比例与模型。
3. 修改后点击“保存修改”，再预检。高级参数仅在确有需要时调整。
4. 预检有问题时按提示修正。费用未知时以官方账单为准。
5. 点击“确认当前任务”，再点击“提交生成（调用付费 API）”。修改参数后需要重新预检和确认。
6. 在资产库按“视频＋生成任务”查看进度。展开分段，试听／预览后打开具体结果。

## 输出位置
标题左侧文件夹图标打开当前设置的输出根目录；它不是所有历史会话的唯一目录。
每个结果可单独打开原文件或所在目录。未生成最终合成文件时，显示的是分段结果；在剪映按原顺序导入，检查衔接后再导出成片。

## 恢复与费用
用“恢复任务”重新打开既有会话。后台生成不会因为关闭手册而停止。
已完成结果保留。生成失败先查看具体错误；重新生成可能新增费用，下载恢复只下载已有结果。
未知请求或中断先核对云端结果与账单，不自动重复提交。
素材失效可在资产库重新定位；结果下载失败在任务详情恢复。手册无法替代真实模型限制与官方账单。

## 高级：本地任务编译
使用已确认的 JSON 方案裁切本地素材，形成供一键生成使用的任务包。它是辅助工具，不是使用一键复刻前必须执行的步骤。

## 常见问题
导入失败：检查 ZIP 和任务协议，不通过时不提交生成。
修改后不能提交：先保存、预检，再确认当前任务。
只有分段：本工作台没有承诺自动剪辑成片，分段到剪映整理。
找不到输出：先在资产库定位具体任务，打开对应结果；标题目录只代表当前配置。
