吃个糖Agent｜音视频转文字｜SenseVoice 模型下载安装指南
======================================================

适合小白：照着下面做即可，不需要安装 Python，也不需要配置 CUDA。

【一、这个模型是什么】

本功能使用：SenseVoice Small INT8
运行框架：sherpa-onnx
用途：在电脑本地把视频/音频识别成文字。

模型支持普通话、粤语、英语、日语、韩语。
本软件默认使用 2024-07-17 INT8 版，模型文件约 228 MB。

【二、先打开模型保存目录】

1. 打开“吃个糖Agent”。
2. 左侧点击“转文字”。
3. 在“音视频转文字”标题右侧，点击 AI 图标。
4. 软件会自动打开模型保存目录。

Windows 默认目录：
D:\吃个糖Agent数据库\models\sensevoice

不要自己修改这个目录名称。

【三、下载官方 INT8 模型】

官方模型文件名：
sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2

官方下载地址：
https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2

为什么默认不是更新的 2025-09-09 版？
官方当前说明中，2025-09-09 版主要加强粤语，但注明不支持标点；本软件需要生成更适合阅读和后续时间轴整理的逐字稿，因此默认使用 2024-07-17 INT8 版，并开启 ITN（数字与标点的模型输出）。不要自行混用两个版本。

如果直接点击地址不能下载，可以在浏览器中打开：
https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models

然后在页面中查找上面的完整文件名。

【四、解压下载文件】

下载的是 .tar.bz2 压缩包。

如果电脑不能直接解压，推荐使用 7-Zip 或 Bandizip。
通常需要解压两次：
1. 先把 .tar.bz2 解压成 .tar；
2. 再把 .tar 解压成文件夹。

解压后会看到一个模型文件夹。

【五、只复制这两个文件】

从解压后的模型文件夹中找到：

1. model.int8.onnx
2. tokens.txt

把这两个文件复制到：

D:\吃个糖Agent数据库\models\sensevoice

最终目录应当像这样：

D:\吃个糖Agent数据库\models\sensevoice\model.int8.onnx
D:\吃个糖Agent数据库\models\sensevoice\tokens.txt

注意：
- 不要把 model.onnx 当成默认模型；它更大，本软件默认使用 INT8 版。
- 不要改 model.int8.onnx 和 tokens.txt 的文件名。
- 不要把这两个文件继续放在多一层子文件夹里。

【六、安装完成后】

回到“转文字”，选择或拖入一个文件，点击“开始转文字”。无需重启。
开始时会自动核验两个文件的 SHA-256，文件未下载完整或版本不一致会明确提示。
模型只需要安装一次；以后升级软件时，模型目录应继续保留，不需要重复下载。

【七、任务保存在哪里】

“音视频转文字”标题右侧第一个文件夹图标用于打开任务保存目录。

默认目录：
D:\吃个糖Agent数据库\outputs\transcription

【八、遇到问题先检查这三件事】

1. model.int8.onnx 是否确实存在；
2. tokens.txt 是否确实存在；
3. 两个文件是否直接位于 sensevoice 文件夹里，而不是又套了一层文件夹。

正确：
D:\吃个糖Agent数据库\models\sensevoice\model.int8.onnx

错误示例：
D:\吃个糖Agent数据库\models\sensevoice\某个解压文件夹\model.int8.onnx

【官方资料】

sherpa-onnx SenseVoice 预训练模型：
https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html

本指南只说明模型文件的下载安装位置，不要求用户安装 Python、CUDA 或开发环境。

【九、实际使用】

选择文件后会显示名称、类型、大小和时长；点击“开始转文字”。
运行时可点击“取消任务”；后台进程退出和临时文件清理后即可开始下一次。
切换到其他页面不会终止任务，返回“转文字”可继续查看进度和结果。

完成后每个任务文件夹只有：
01_完整逐字稿.txt
02_时间帧逐字稿.txt

可直接查看、复制，或打开本次文件夹。两个 TXT 都是 UTF-8，兼容 Windows 记事本。

【十、程序与模型分开保存】

官方 sherpa-onnx v1.13.8 Windows x64 static MT Release 运行时已随完整程序提供。
不依赖 Python、CUDA、Node 开发环境或额外 Visual C++ 运行库。
不要单独移动 exe；请保留整个程序文件夹。模型不放入程序安装目录。

程序内运行时位置：resources\app\resources\sherpa-onnx\sherpa-onnx-offline.exe
模型仍保存在点击 AI 图标打开的目录里（以实际配置的数据根目录为准）。
约 228 MiB 的模型不会重复打进程序包；升级时继续使用原模型目录。

【十一、时间帧与识别边界】

时间帧格式：[00:00.820 --> 00:03.460]；超过一小时以累计分钟显示，例如 60:00.000。
时间来自 SenseVoice CTC token 起点；该模型的时间粒度约 60 毫秒，三位小数是显示格式，并不代表毫秒级识别精度。
该版本未返回 token 持续时长；片段结束采用下一 token 起点或检测到的静音边界，末段以原音轨结束为界。
没有使用平均分配时间或另一个 AI 猜测时间。内部原始识别数据保存在数据目录 data\transcription，用户结果目录仍只有两个 TXT。
优先按完整词语、标点和停顿分段，目标 2–5 秒，完整语义优先时可能超过 5 秒。

单文件最长 4 小时。长录音在实际静音处拆分以控制内存，不剪掉原始静音，时间偏移会累加回原视频。
如果存在超过 2 分钟始终无可检测停顿的连续音频，会明确提示先按完整语句拆分，避免静默截断或卡死。
这不是人工校对稿。口音、噪声、背景音乐、同音字和数字都可能造成识别错误，模型自动语言判断也可能出错。
软件不会另行总结、润色或补写，请在正式使用前对照原音频核对关键内容。

失败的详细技术日志：<用户数据根目录>\logs\transcription.log
