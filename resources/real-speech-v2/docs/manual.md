# 真人口播 V2 第一阶段使用手册

1. 在“模型与 API”配置阿里云北京账户及Workspace；复刻音色沿用已有音频模块。
2. 真人口播首页填写任务名称、选择复刻音色、粘贴REAL_SPEECH_EXECUTION_PLAN_V2，然后导入校验。
3. 核对原稿、Window、只读导演意图和待验证能力；明确确认Plan来自你已确认的导演方案后保存。无需另外上传导演稿。
4. 所有锚点来自Plan，没有自动选段。试演生成完整关联Window，多个锚点可复用同一音频。通过判断由你填写。
5. 逐Window或勾选多个Window生成；每次成功追加V1/V2/V3，旧文件永久保留。新生成不会替换已有选中版本。播放A/B后点击选择；回滚明确恢复该版本配置和音频。
6. 每个Window有独立Patch框。粘贴严格Patch，查看Diff、确认目标与锁，才能应用。说明修订不触发TTS；执行修订创建目标Window的独立生成任务。版本基线过期时重新导出诊断包给ChatGPT。
7. 全篇、单Window或多选诊断导出ZIP：WAV、Plan、当前配置、真实生成参数、选中版本及反馈。软件不诊断声音。API Key不会进入导出。
8. 选定所有Window音频后最终拼接，旧拼接也保留。确认完整试听后标记Golden并锁定引用Window。
9. 结果未知时禁止自动重发。先尝试从已有响应恢复下载，无额外TTS请求；没有响应时先核对控制台计费，再明确允许新请求。
10. 旧v1.2.9任务入口只读，不改旧数据库、不删旧WAV。
