# 吃个糖 Agent｜阶段3：任务包转换 V2.2

## 唯一目标

将已确认的《阶段2_Wan任务表.md》和真实素材转换为吃个糖 Agent v1.2.2 可直接导入的 ZIP。本阶段只转换和验证，不重新设计内容。

## 协议锁定

- 应用版本：1.2.2。
- 机器协议仍为 `schema_version: "1.2.0"`。
- `package_type` 必须为 `chigetang.wan-task`，`engine` 必须为 `wan3`。
- ZIP 根目录直接包含 `manifest.json`、`assets/`、`prompts/`；不多套顶层文件夹。
- 不新增字段，不使用 `reference_order`，不改现有目录结构。

## manifest 结构

```json
{
  "schema_version": "1.2.0",
  "package_type": "chigetang.wan-task",
  "task_id": "unique_task_id",
  "task_name": "用户可读任务名",
  "engine": "wan3",
  "assets": [],
  "shared": {
    "params": {
      "duration": -1,
      "audio": false,
      "resolution": "720P",
      "ratio": "9:16",
      "seed": -1,
      "watermark": false,
      "prompt_extend": false
    }
  },
  "segments": []
}
```

## 多素材写法

`assets[]` 中每个真实文件独立声明 `id/type/path/usage/sha256`。只有 `usage: "wan_reference"` 可以进入 bindings。

```json
"assets": [
  {"id":"person.01","type":"image","path":"assets/person_01.jpg","usage":"wan_reference","sha256":"<64位真实小写SHA256>"},
  {"id":"person.02","type":"image","path":"assets/person_02.jpg","usage":"wan_reference","sha256":"<64位真实小写SHA256>"},
  {"id":"motion.01","type":"video","path":"assets/motion_01.mp4","usage":"wan_reference","sha256":"<64位真实小写SHA256>"},
  {"id":"voice.01","type":"audio","path":"assets/voice_01.wav","usage":"wan_reference","sha256":"<64位真实小写SHA256>"}
]
```

一个别名只绑定一个素材 ID：

```json
"bindings": {
  "person": "person.01",
  "person_side": "person.02",
  "motion": "motion.01",
  "voice": "voice.01"
}
```

Prompt 必须对应写 `@person @person_side @motion @voice`。不得写 `"person": ["person.01","person.02"]`，不得把 `@` 写进 bindings 键。

## 单任务与多任务模板定义

- 单任务模板：一个 manifest，一个 Segment，展示同段多图、多视频、多音频绑定。
- 多任务模板：一个 manifest，多个 Segment；软件导入后每个 Segment 创建一个独立生成任务。
- 现有协议不在一个 ZIP 内放多个 manifest，也不增加 `tasks[]`。
- 多任务模板中每段必须显式绑定所有需要的素材；不得猜测或暗中沿用上一段。

## 转换流程

1. 复制对应 V2.2 成功模板的 ZIP 结构。
2. 替换真实素材，按真实内容填写类型与用途。
3. 为每份素材计算实际文件字节的 SHA-256，再写入 manifest。
4. 为每个 Segment 写独立 UTF-8 Prompt 文件、整数 `duration_seconds`、可选 `source_range_ms` 和 bindings。
5. 逐段验证：Prompt `@别名` ↔ bindings 别名 ↔ assets ID ↔ 真实文件类型／用途完全一致。
6. 确认 `audio` 是布尔值且与用户确认的 Wan 声音开关一致。
7. 检查时长、素材数量、格式、文件大小、视频帧率及参考视频＋输出不超过 30 秒。
8. ZIP 打包后重新解压，验证 CRC、路径、文件存在、SHA-256 和未声明文件。

## 最终验收

- 任务包只包含 manifest 声明的文件。
- `task_id` 唯一，Segment ID 和 order 唯一且连续。
- 所有输出时长均为整数。
- 多素材在每段不串位，不丢失，不重新分类。
- Prompt 保留阶段2的人物、产品、动作、镜头、情绪和禁止项，不重写内容。
